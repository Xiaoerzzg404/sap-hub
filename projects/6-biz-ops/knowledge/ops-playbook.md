# 法人经营 · 经营流程 playbook（单人版）

> 设计前提：你是唯一的人，时间是瓶颈。每个流程都按"最省你时间"设计。

## 1. 获客（漏斗，复用现有自媒体）
公众号/视频号/小红书（已日更）→ 免费体验课/直播 → 体验课结尾给 L1/L2 名额
→ 报名。原则：**不投流、不冷启动**，只把现有内容流量往体验课导。
关键素材：那条"中国 SAP 顾问最容易说错的 5 句日语"——天然引流钩子，
归 3 号生产，本流程负责把它接到体验课转化。

## 2. 交付（控住你的时间）
- 用 v3 训练课五动作（听·读·换·演·录），结构固定 = 每期备课成本递减。
- 小班而非 1v1（阶段一），单位时间产出最大化。
- 学员录音作业：只批 3 类错（最影响专业感/理解/最常反复），不逐条改——
  这是保护你时间的硬纪律，别破例。

## 3. 复购（offer ladder 内向上）
体验课→训练营→1v1 诊断→（未来）会员。每个学员结课时，给明确的"下一步
该买什么"。复购率是单人生意的命——拉新贵，复购近乎零成本。

## 4. 口碑闭环
学员成长案例 → 喂给 3 号做招生内容 → 带来新学员 → 新案例。
这个闭环一旦转起来，获客成本趋近于 0，是这门生意能否成立的关键。

## 5. 你的时间分配纪律（最重要）
单人创业最大浪费是"什么都自己干且没优先级"。建议每周时间预算化：
- 大头给"只有你能做的"：亲授、课程内容把关、定位决策。
- 能交给 AI/流程的（情报收集、内容初稿、排版、整理）→ 交出去（1/2/3 号体系）。
- 定期问自己一句：这件事，是不是只有我能做？不是 → 不该占你的时间。

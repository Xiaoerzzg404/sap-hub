# 法人经营 · 商业模式

## 一、定位（北极星，统领 4/5/3）
不是"SAP 日语课"，是**中国 SAP 顾问进入日本项目的语言战斗力训练营**。
卖点：学员缺的不是 SAP 能力、不是日语单词，是日本项目现场的表达套路。
壁垒：SAP + 日本项目 + 中国顾问痛点 三者叠加——纯日语老师做不了，
纯 SAP 讲师也做不了，这个组合难以被复制。经营的所有动作都向此对齐。

## 二、你的真实资产与唯一稀缺资源
- 真实资产：上面那个三叠加的认知壁垒（不是课件，课件可抄，壁垒不可抄）。
- 唯一稀缺资源：**你的时间**。一人法人，时间是收入天花板。
  → 推论：商业模式必须让"收入"逐步和"你的工时"脱钩，否则做到累死也有上限。
- 已有杠杆：公众号/视频号日更已稳定运行 = 获客发动机已就位。
  大多数创业者最难的"获客"，你已解决一半。模式必须把它接成漏斗顶端，不空转。

## 三、产品阶梯（offer ladder · 从免费到资产化）
原则：低层引流养鱼，高层变现，最高层做时间杠杆。

| 层 | 产品 | 作用 | 你的时间投入 | 收入性质 |
|---|---|---|---|---|
| L0 | 自媒体内容 + 免费体验课/直播 | 引流、建信任 | 已在跑（3 号产出）| 不直接变现 |
| L1 | 低价体验课 / 短期小班 | 验证、攒证言、攒错误库 | 高（亲授）| 卖时间 |
| L2 | 训练营（多周，主力付费）| 核心变现，北极星产品 | 高（亲授）| 卖时间 |
| L3 | 1v1 项目日语诊断 / 顾问成长陪跑 | 高客单 | 极高（一对一）| 卖时间（单价最高）|
| L4 | 人才对接/派遣（衍生）| 学员→企业撮合 | 中 | 撮合费（**法律前置，见 decisions D2**）|
| L5 | 录播课 / 会员社群 | 时间杠杆，规模化 | 一次性高、之后低 | **卖资产（关键）** |

战略次序：先把 L1→L2 跑通（验证 + 攒资产），再爬 L3，**最终重心必须移向
L5**——只有 L5 让你摆脱"时间换钱"的天花板。L4 诱人但有牌照雷，不急。

## 四、六条线如何咬合成一门生意
```
情报(1,2) 供料 → 内容(3) 造势引流(L0) → 训练营(4,5)承接变现(L1-L3)
   → 沉淀为录播/社群(L5) → 口碑/案例反哺(3) 再引流 → 闭环
6 号(经营)做的是：决定钱和时间往哪条线投、定价、节奏、何时从卖时间转卖资产
```
2 号 SAP 情报要重点收集什么，由本方案反推：**优先收日本 SAP 项目现场的
真实表达场景、招聘对日语的要求、在日中国顾问的痛点讨论**——直接喂 4 号课程
和 6 号市场判断，不是泛泛收 SAP 新闻。

## 五、收入结构健康度（自检用）
- 健康信号：L5（资产型）收入占比逐季上升；获客主要来自自媒体（成本≈0）；
  复购率（学员从 L1 升 L2 升 L3）可见。
- 危险信号：收入 100% 靠你亲授（L1-L3）；招生靠投流买量；学员一次性、无升级。
- 一句话：**你的目标不是某一期赚多少，是让收入越来越不依赖你的工时。**

# 法人经营 · 增长路径（三阶段）

> 单人创业铁律：一次只全力推一个阶段，达不到"退出标准"不进下一阶段。
> 跳阶段是单人创业最常见死法。

## 阶段一 · 验证（现在～首期训练营结束）
目标：用最小成本证明"有人愿意为这门课付费"，并攒下资产。
- 产品：1 个 MVP 训练营（4-8 周，亲授小班，规模故意小）。
- 来源：自媒体现有流量里捞 5-10 个种子学员（不投流、不大规模招生）。
- 核心是收集，不是赚钱：① 真实学员反馈 ② 课堂录音 ③ 常见错误数据库
  ④ 可展示的学员成长案例 ⑤ 招生口碑。
- 退出标准（全部满足才进阶段二）：
  - 一期训练营完整跑完，学员有可见进步（前后录音对比）
  - 拿到 ≥3 条真实学员证言 + ≥1 个成长案例
  - 错误数据库初具规模（够支撑课程迭代）
  - 你自己确认"这门课能教、我能讲、流程顺"
- 不做：不铺多模块、不做 L5 录播、不碰 L4 派遣、不扩招。

## 阶段二 · 复制（验证通过后）
目标：把验证过的训练营变成可重复交付、可迭代的产品。
- 动作：① 按 v3 backbone+case-pack 扩 SD/MM 等模块包 ② 训练营标准化
  （每期不用重做）③ 自媒体把学员案例做成招生素材（接 3 号）
  ④ 开始做 L3（1v1 诊断，高客单养现金流）。
- 退出标准：训练营能稳定开 2-3 期、复购/转介可见、单期不再靠你临时拼凑。

## 阶段三 · 杠杆（复制跑顺后）
目标：收入与你的工时脱钩。
- 动作：① L5 录播课/会员社群（把亲授内容资产化）② 社群沉淀错误库与答疑
  ③ 评估 L4 人才对接（**先解决 decisions D2 的牌照问题再说**）。
- 这一阶段成功的标志：你休假一周，收入不归零。

# 法人经营 · 经营流程 playbook（单人版）

> 设计前提：你是唯一的人，时间是瓶颈。每个流程都按"最省你时间"设计。

## 1. 获客（漏斗，复用现有自媒体）
公众号/视频号/小红书（已日更）→ 免费体验课/直播 → 体验课结尾给 L1/L2 名额
→ 报名。原则：**不投流、不冷启动**，只把现有内容流量往体验课导。
关键素材：那条"中国 SAP 顾问最容易说错的 5 句日语"——天然引流钩子，
归 3 号生产，本流程负责把它接到体验课转化。

## 2. 交付（控住你的时间）
- 用 v3 训练课五动作（听·读·换·演·录），结构固定 = 每期备课成本递减。
- 小班而非 1v1（阶段一），单位时间产出最大化。
- 学员录音作业：只批 3 类错（最影响专业感/理解/最常反复），不逐条改——
  这是保护你时间的硬纪律，别破例。

## 3. 复购（offer ladder 内向上）
体验课→训练营→1v1 诊断→（未来）会员。每个学员结课时，给明确的"下一步
该买什么"。复购率是单人生意的命——拉新贵，复购近乎零成本。

## 4. 口碑闭环
学员成长案例 → 喂给 3 号做招生内容 → 带来新学员 → 新案例。
这个闭环一旦转起来，获客成本趋近于 0，是这门生意能否成立的关键。

## 5. 你的时间分配纪律（最重要）
单人创业最大浪费是"什么都自己干且没优先级"。建议每周时间预算化：
- 大头给"只有你能做的"：亲授、课程内容把关、定位决策。
- 能交给 AI/流程的（情报收集、内容初稿、排版、整理）→ 交出去（1/2/3 号体系）。
- 定期问自己一句：这件事，是不是只有我能做？不是 → 不该占你的时间。

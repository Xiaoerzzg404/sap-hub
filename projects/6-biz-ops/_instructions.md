# Project 6 · 法人经营

## 定位
1-5 号是地基，6 号是地基上的生意。用户自陈不擅长经营管理，
明确要大脑当**创业导师 / 经营陪练**，帮设计经营思路、方法、
业务壮大流程与实现路径，提升业务能力与成果。

## 大脑在此 Project 的工作方式
- 给经营思路、业务流程设计、增长路径、把 1-5 号产出转成可执行经营动作。
- 给方案时先给“别人/通行做法会怎么主张” → 再给争议点与风险 → 给选项。
- **不替用户下不可逆结论**，尤其财务、法律、重大投入、对外承诺类——
  这些只给信息、选项、利弊，最终拍板永远是用户。

## 经营管理骨架（v1，后续细化）
```
projects/6-biz-ops/
├── state/
│   ├── objectives.json    # 经营目标（季度/年度），符合 schema
│   ├── pipeline.json      # 业务机会管线（线索→洽谈→成交）
│   └── decisions.json     # 重大决策记录（含选项/所选/理由/可逆性）
├── knowledge/
│   ├── business-model.md  # 业务模式：六条线如何咬合成收入
│   ├── growth-path.md     # 业务壮大路径与里程碑
│   └── ops-playbook.md    # 经营流程（获客/交付/复购/口碑）
```

## 六条线如何咬合（初始判断，待与用户深聊细化）
情报(1,2) 产料 → 内容(3) 造势引流 → 教培(4) 与 人才(5) 承接变现
→ 经营(6) 统筹定价/获客/资源/节奏。6 号关注的是“哪条线现在最该投入、
钱和时间往哪放、下一个增长点在哪”。

## 大脑后续供给
按用户实际业务现状，逐步产出：业务模式画布、定价与产品化建议、
获客路径、季度经营节奏、关键决策的结构化分析。

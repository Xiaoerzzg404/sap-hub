# Project 5 · SAP 顾问成长与人才

## 定位
4 号的衍生与升级。链路：2 号情报 → 做强 3 号自媒体 → 自媒体引流来
SAP 人才/学生 → 5 号提供培训/成长/咨询/派遣 → 反哺 6 号经营。

## 三块职能
1. **顾问成长体系**：承接 4 号能力模型，向上做完整成长路径
   （日语 → 初级 → 中级 → AI 顾问）。
2. **人才档案**：来的学员/顾问，结构化建档。
3. **人企对接**：企业需求结构化，做撮合记录与服务（咨询/派遣）。

## 数据结构（schema 化，便于后续平台化）
```
projects/5-sap-talent/
├── state/
│   ├── talents/<id>.json     # 人才档案：能力分级/方向/日语级/状态
│   ├── demands/<id>.json     # 企业需求：技能/级别/地点/时间窗
│   └── matches/<id>.json     # 撮合记录：talent_id + demand_id + 进展
├── knowledge/
│   ├── growth-path.md        # 成长路径（承接 4 号）
│   └── service-playbook.md   # 咨询/派遣服务流程
```
talent/demand/match 三类 JSON 均符合 state.schema.json，
额外字段自定义但五个必填字段不省。

## 边界
人才派遣/人企对接涉及合同、合规、个人信息——大脑只设计流程与结构，
具体法律/合规与最终决策由用户拍板（见 6 号经营红线一致）。
个人信息不写入 git 跟踪文件（按 AGENTS.md 禁止项）。

## 大脑后续供给
成长路径细化、服务 playbook、撮合方法论；随 4 号课程升级同步升级。

# SAP 人才信任网络 Playbook

- updated_by: codex
- updated_at: 2026-05-23T23:46:43+09:00
- 适用范围：5 号 SAP 顾问成长与人才。
- 隐私红线：本文件只设计结构和流程，不保存真实个人信息。真实姓名、联系方式、履历、薪酬、签证、客户名、项目名不得写入 git 跟踪文件。

## 1. 核心判断

5 号不是传统猎头，也不是普通社群。它应该先成为“顾问成长和可信展示系统”。

你要解决三方问题：

1. 顾问的问题：我怎么进入日本 SAP 项目？我的日语、SAP、AI 能力差在哪里？怎么被可信地看见？
2. 企业的问题：我怎么找到靠谱、能沟通、懂流程、能落地的 SAP 顾问？
3. 你自己的问题：我怎么不靠一个人硬扛，把课程、人才、内容、企业需求变成可运转系统？

答案是：

```text
训练产生能力
作品证明能力
画像结构化能力
社群维持关系
教练提高你带人的能力
合规边界保护公司
```

## 2. 人才分层

| 层级 | 人群 | 你提供什么 | 你期待什么 |
| --- | --- | --- | --- |
| T0 观察者 | 自媒体读者、旁听者 | 免费内容、公开诊断 | 关注、转发、报名 |
| T1 学员 | SAP 日语或 AI 课程学员 | 训练、反馈、模板 | 作业、复盘、证言 |
| T2 种子人才 | 稳定学习且可展示的人 | 成长画像、作品打磨 | 脱敏案例、社群贡献 |
| T3 助教候选 | 能帮助新人且守规则的人 | 助教训练、身份、报酬机会 | 运营协作、初筛反馈 |
| T4 合作顾问 | 中高级顾问或专家 | 共同内容、课程合作 | 专业背书、专题分享 |
| T5 企业侧伙伴 | PM、SIer、企业 IT/业务负责人 | 人才框架、培训方案 | 需求反馈、市场判断 |

不要跳过 T1 到 T3。没有训练和作品，直接做人企对接会变成风险。

## 3. 顾问信任飞轮

```text
公开内容
→ 免费诊断
→ 小班训练
→ 作业与录音
→ 脱敏成长案例
→ 顾问画像
→ 作品展示
→ 企业需求理解
→ 新内容和新课程
```

飞轮每转一次，你多三类资产：

1. 内容资产：文章、视频、案例。
2. 训练资产：错误库、表达模板、作业题。
3. 人才资产：脱敏画像、作品集、助教候选人。

## 6. 获取人才的具体动作

### 6.1 内容入口

每周固定 2 类内容：

1. 痛点内容：日本 SAP 项目现场最容易卡住的表达、汇报、确认、拒绝、障害对应。
2. 成长内容：FICO 顾问如何升级为 AI 时代的业务顾问。

每篇内容都只引导一个动作：

```text
想做一次脱敏能力诊断，请填写“SAP 日本项目成长画像”。
```

### 6.2 免费诊断

每周或每两周一次，主题示例：

1. “日本项目会议里，中国 SAP 顾问最容易直译的 5 句话”
2. “FICO 顾问如何用日语解释月结问题”
3. “SAP AI 时代，FICO 顾问还值钱吗”

诊断后只做三件事：

1. 给一个改进建议。
2. 邀请加入训练营或成长档案。
3. 请求允许脱敏记录常见问题。

### 6.3 作品展示

作品不是简历。早期作品可以是：

1. 一段日语会议表达改写。
2. 一个 FICO 业务场景的中日双语说明。
3. 一个 SAP AI 用例说明。
4. 一个脱敏项目复盘。
5. 一张能力成长前后对比表。

作品展示必须经过本人同意，并脱敏。

## 7. 激励机制

### 7.1 顾问为什么愿意参与

1. 能得到真实 SAP 日本项目表达反馈。
2. 能形成作品集，而不是只写简历。
3. 能被同圈层看见。
4. 能获得成长路径和等级感。
5. 未来有合规机会信息时，有更好的准备度。

### 7.2 助教为什么愿意参与

1. 身份：从学员升级为助教候选。
2. 能力：训练反馈、组织、表达和带人能力。
3. 作品：可写入自己的成长作品集。
4. 报酬：明确任务可以付费，先小额、短周期、按交付。
5. 机会：优先参与公开课、案例共创、训练营运营。

### 7.3 外部导师为什么愿意参与

1. 被看见：在垂直 SAP 顾问圈获得专业曝光。
2. 有价值：把经验传给后辈。
3. 有合作：未来课程、企业培训、专题分享可以合作。
4. 有边界：不要求他们承担日常运营。

## 8. 助教训练流程

### 8.1 选拔

标准：

1. 完成至少一个训练单元。
2. 作业稳定。
3. 反馈态度好。
4. 能遵守隐私和事实核查规则。
5. 每周可投入固定时间。

### 8.2 训练

第一月只训练四件事：

1. 如何按模板提醒作业。
2. 如何汇总问题。
3. 如何标注日语表达问题。
4. 如何把不确定内容标成 `Need Confirmation`。

### 8.3 交付

每周交付物：

1. 作业提交清单。
2. 常见错误 Top 5。
3. 需要你判断的 SAP 事实清单。
4. 学员情绪或节奏风险清单。

## 9. 企业侧信任方法

早期不要说“我有人才可以推荐给你”。先说：

```text
我在做面向中国 SAP 顾问的日本项目语言和 AI 能力训练。
想请教你：你们项目里最缺的顾问能力是什么？什么样的人会让 PM 省心？
```

企业侧访谈问题：

1. 你最近项目最缺哪类 SAP 角色？
2. 候选人最常见的失败点是什么？
3. 日语沟通里最影响项目的是会议、文档、邮件还是障害对应？
4. AI、S/4HANA Cloud、BTP 对顾问要求有什么变化？
5. 如果有一个训练过的顾问作品集，你最想看到什么证据？

访谈产物：

1. 需求画像。
2. 课程改进点。
3. 能力评估标准。
4. 内容选题。

## 10. 合规边界

### 10.1 当前可做

1. 训练课程。
2. 能力诊断。
3. 脱敏作品展示。
4. 企业需求访谈。
5. 公开信息整理。
6. 不涉及个人匹配的培训建议。

### 10.2 需要专业确认后才能做

1. 收费向企业推荐特定候选人。
2. 向求职者推荐特定企业或岗位并居中沟通。
3. 收成功费、介绍费、推荐费。
4. 代企业筛选候选人。
5. 代求职者处理求职沟通。
6. 派遣、准委任、业务委托等具体合同结构。

### 10.3 禁止写入 git 的信息

1. 真实姓名。
2. 电话、微信、邮箱、地址。
3. 签证、薪酬、身份证明。
4. 客户名、项目名、未公开岗位。
5. 履历书原文。
6. 合同、报价、发票、银行信息。

## 12. 每周例行流程

1. 周一：更新人才画像和需求画像。
2. 周二：发布 1 个痛点内容。
3. 周三：做 1 个顾问或企业访谈。
4. 周四：整理 1 个脱敏案例或作品。
5. 周五：助教/协作者复盘。
6. 周日：更新 6 号经营目标，决定下周最多 3 件事。

## 13. 对小白老板的提醒

1. 你不需要一开始会管理人。你只需要把每件事写成模板，让别人能照着做。
2. 你不需要一开始会激励人。你先做到“给反馈、给成长、给舞台、守信用”。
3. 你不需要一开始就招员工。先用协作者、助教、导师、访谈对象组成轻网络。
4. 你不需要一开始就做人力资源牌照业务。先做训练和成长，等法律边界清楚后再升级。
5. 你最重要的资产是可信，不是规模。

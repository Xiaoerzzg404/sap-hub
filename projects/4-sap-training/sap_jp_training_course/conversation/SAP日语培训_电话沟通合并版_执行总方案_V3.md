# 0. 一页总判断

## 0.1 最核心结论

这门课不能做成普通日语课，也不能做成纯 SAP 功能培训。

它应该被设计成：

> **懂 SAP 的人，教 SAP 顾问在日本项目里真正用得上的日语。**

更准确的产品定位是：

> **SAP顾问日本项目日语实战课 / SAP FICO顾问日本项目日语专班**

核心卖点是：

> **让已经懂 SAP 的顾问，能够用日语进入面试、听懂会议、说明业务流程、汇报测试结果，并逐步适应日本 SAP 项目现场。**

## 0.2 第一阶段最应该聚焦什么

第一阶段不要做成“大而全”的 SAP 日语大学课程，而要先做一个可销售、可交付、可复盘的小型 MVP：

> **24课时左右的小班实战课 + 一场公开课/试听课 + 一套招生资料 + 一套作业交付体系。**

第一阶段的成功标准不是“马上赚大钱”，而是：

| 目标 | 判断标准 |
|---|---|
| 市场验证 | 是否有精准 SAP 顾问愿意报名 |
| 课程验证 | 学员是否觉得“这不是普通日语课，确实贴近项目” |
| 交付验证 | 你是否能稳定备课、上课、纠错、布置作业 |
| 口碑验证 | 学员是否愿意推荐给其他顾问 |
| 延展验证 | 是否自然产生 1 对 1、面试指导、项目咨询等需求 |

> 面向已有 SAP 经验和一定日语基础的顾问，围绕日本 SAP 项目真实场景，训练面试、会议、流程说明、测试汇报、客户沟通等高频表达。

## 2.4 课程边界

| 边界问题 | 明确答案 |

| 是否只是 SAP 课？ | 也不是。它不替代 SAP 功能培训，而是解决“怎么用日语讲 SAP”。 |

# 3. 核心论点整理

## 3.1 论点一：你的机会不在“教日语”，而在“场景翻译能力”

一般日语老师能教语法、听力、会话，但很难教：

- 如何用日语说明 AP 付款流程；
- 如何用日语说明 AR 入金消込；
- 如何在会议中汇报测试进捗；
- 如何向客户解释 Fit/Gap；
- 如何在日语面试中讲清 FICO 项目经验；
- 如何用日本项目现场能接受的表达推进课题。

你的优势在于：

> **你知道 SAP 顾问脑子里想表达什么，也知道日本项目现场应该怎么说。**

## 3.2 论点二：课程应该卖“项目表达能力”，不是卖“知识堆积”

学员真正买的不是术语表，也不是 PPT 页数，而是：

| 学员痛点 | 课程解决方式 |
|---|---|
| 学了 N2，但项目会议里说不出来 | 用会议场景反复演练 |
| 懂 FICO，但不会用日语说明业务流程 | 让学员输出流程说明稿 |
| 面试时一问项目经验就卡住 | 建立项目经验表达模板 |
| 看得懂资料，但不敢问问题 | 训练确认、提问、反问表达 |
| 做测试但不会汇报缺陷 | 训练 Issue / Defect / Retest 表达 |
| 不知道日本项目怎么沟通 | 教“日本项目现场常用说法”和“不要这么说” |

## 3.3 论点三：第一阶段不要高价大课，要先做可验证小班

原因：

1. SAP 培训市场不是“高价就好卖”；
2. 个人 IP 课程需要先建立信任；
3. 你第一次做培训，需要控制交付压力；
4. 小班更容易做出口碑和案例；
5. 后续可以通过 1 对 1、面试指导、项目咨询提高客单价。

建议第一期：

| 项目 | 建议 |
|---|---|
| 课时 | 24课时左右 |
| 人数 | 6-12人 |
| 价格 | 启动价 2,800-3,600 元；标准价 3,980-4,980 元 |
| 模式 | 直播小班 + 作业 + 点评 + 群答疑 |
| 目标 | 市场验证、口碑积累、课程打磨 |

## 3.4 论点四：课程必须让学员开口，不是只听老师讲

每节课都应该有一个明确的学员交付物：

- 1分钟自我介绍录音；
- 3分钟项目经验说明；
- AP/AR/AA/GL 流程日语说明稿；
- 测试结果汇报稿；
- 缺陷说明模板；
- 面试问答稿；
- 模拟客户说明视频；
- 结业发表材料。

老师的核心价值不是“讲很多”，而是：

> **听学员说，指出哪里不自然、不专业、不符合日本项目现场习惯，然后给出更好的表达。**

## 3.5 论点五：公开课是市场教育入口，不是免费讲一堆知识

公开课要完成三个目标：

1. 让学员意识到普通日语课解决不了 SAP 项目表达问题；
2. 让学员相信你有真实日本 SAP 项目经验；
3. 让学员愿意报名小班或预约 1 对 1 诊断。

公开课不要太散，建议主题统一为：

> **会 SAP 又会日语，为什么可能是华人顾问进入日本项目的稀缺机会？**

## 3.6 论点六：培训只是入口，后续要做服务菜单

完整商业漏斗：

```text
短视频 / 公众号 / 小红书 / 社群
        ↓
公开课 / 试听课
        ↓
24课时小班实战课
        ↓
1对1面试指导 / 项目日语陪跑 / 资料表达辅导
        ↓
顾问推荐 / 企业定制培训 / 项目支援
        ↓
长期社群与知识库产品
```

| 条件 | 画像 |
|---|---|
| SAP经验 | 2-10年 SAP 项目经验 |

- MM / SD / PP / ABAP / Basis 等模块顾问；
- 已经在日本项目中，但会议、文档、客户沟通压力大；
- 想未来赴日或远程参与日本项目；
- 想训练日语面试和项目经验说明的人。

## 4.3 暂不建议招的人

| 类型 | 原因 |

| 日语零基础 | 会拖慢课程节奏 |
| SAP 零基础 | 无法围绕真实项目场景输出 |
| 期待包就业的人 | 容易产生交付争议 |
| 只想听不想练的人 | 不符合课程训练模式 |

# 7. 学员作业与交付体系

## 7.1 每节课必须有交付物

课程不能变成“老师讲得很爽，学员听完就忘”。

每节课都要有一个小交付物，并形成学员成长轨迹。

| 作业类型 | 示例 | 评价标准 |
|---|---|---|
| 录音 | 自我介绍、流程说明 | 是否敢说、结构是否清楚 |
| 文稿 | 面试回答、会议汇报 | 是否符合日本项目表达 |
| 模板 | Issue、Defect、进捗 | 是否能直接用于项目 |
| 角色扮演 | 客户说明、会议发言 | 是否自然、专业、能互动 |
| 结业发表 | 3-5分钟流程说明 | 是否能独立完成项目表达 |

## 7.2 作业点评标准

| 维度 | 评价要点 |
|---|---|
| 业务准确性 | SAP 逻辑是否说对 |
| 日语自然度 | 是否像日本项目现场会说的话 |
| 结构清晰度 | 是否按背景、现状、问题、下一步展开 |
| 敬语与语气 | 是否礼貌但不过度生硬 |
| 可复用性 | 是否能变成自己的模板 |
| 现场适应性 | 是否适合会议、面试、客户说明 |

# 8. 公开课设计

## 8.1 推荐主题

主标题：

> **会 SAP 又会日语，为什么可能是华人顾问进入日本项目的稀缺机会？**

备选标题：

1. SAP顾问学日语，到底应该学什么？  
2. 为什么普通日语课解决不了 SAP 顾问的项目沟通问题？  
3. 从 FICO 顾问视角看日本 SAP 项目现场日语  
4. 懂 SAP 但不会日语表达，如何突破日本项目面试和会议？  
5. SAP 顾问如何把日语变成项目竞争力？  

## 8.2 60分钟公开课结构

| 时间 | 内容 | 目的 |
|---:|---|---|
| 0-5分钟 | 你的自我介绍 | 建立信任 |
| 5-15分钟 | 为什么普通日语课解决不了 SAP 项目问题 | 放大学员痛点 |
| 15-25分钟 | 日本 SAP 项目常见沟通场景 | 让学员看到真实场景 |
| 25-40分钟 | 示例演示：普通日语 vs 项目日语 | 展示课程差异化 |
| 40-50分钟 | 24课时课程体系说明 | 转化报名 |
| 50-60分钟 | 适合/不适合人群、价格、答疑 | 筛选精准学员 |

## 8.3 公开课里必须演示的例子

建议现场演示一个最直观的例子：

### 普通说法

> 支払いの処理をします。請求書を入れて、支払います。

### 项目现场说法

> 仕入先請求書を計上した後、支払条件に基づいて支払予定日が決定されます。その後、支払提案を作成し、内容を確認したうえで支払実行を行います。必要に応じて、源泉税や銀行データ、支払方法の設定も確認します。

这个对比能让学员立刻明白：

> **不是日语会不会的问题，而是你会不会用项目语言讲 SAP。**

|---|---|
| BF/BFC更新影响确认 | 如何在会议中说明影响范围 |

## 15.2 可用表达

| 日文表达 | 中文含义 | 课程用途 |
|---|---|---|
| 更新内容を確認してください | 请确认更新内容 | 任务指示 |
| ベースラインテストに影響があります | 对Baseline Test有影响 | 影响说明 |
| N列、O列を埋めてください | 请填写N列和O列 | 具体任务 |
| 英語でコメントを残してください | 请用英文留下备注 | 作业/任务要求 |
| 今週中に対応してください | 请本周内处理 | 期限表达 |
| 不明点があれば連絡してください | 如有不明点请联系 | 会议结束语 |
| ステータスを更新してください | 请更新状态 | 状态管理 |

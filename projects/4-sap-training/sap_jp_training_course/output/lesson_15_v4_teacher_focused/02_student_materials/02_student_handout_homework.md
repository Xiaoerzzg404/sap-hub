# Lesson 15 v4 学生讲义与课后作业

updated_by: codex
updated_at: 2026-05-19T01:35:49+09:00

## 1. 本课主场景

需求访谈中，业务用户说“这个流程很麻烦”。顾问需要追问具体发生时间、对象、频率、影响、期待改善。

## 2. 硬指标 5 句

1. 現行業務では / どのように処理されていますか。
2. 月次締めの際に / どの作業に最も時間がかかっていますか。
3. 例外処理が発生する条件を / 教えていただけますでしょうか。
4. 課題としては / 手作業が多く確認漏れが発生しやすいという理解でよろしいでしょうか。
5. 具体例を一つ / いただけますでしょうか。

## 3. 核心句型速查

### 現行業務では、どのように処理されていますか。
- 中文：询问现行业务中实际如何处理。
- 场景：As-Is 访谈开头，先听事实，不先给方案。
- SAP 例句：現行業務では / 請求書の承認をどのように処理されていますか。
- 中式错误：今はどうやっていますか。
- 更自然：現行業務では / どのように処理されていますか。

### 〜の場合は、どの部署が承認しますか。
- 中文：询问某种情况下由哪个部门审批。
- 场景：确认例外处理、审批路线、责任部门。
- SAP 例句：金額差異がある場合は / どの部署が承認しますか。
- 中式错误：この時、誰がOKしますか。
- 更自然：差異がある場合は / どの部署で承認されますか。

### 課題としては〜という理解でよろしいでしょうか。
- 中文：复述并确认自己理解的课题。
- 场景：访谈收束、避免误解、确认记录内容。
- SAP 例句：課題としては / 手作業が多く確認漏れが発生しやすいという理解でよろしいでしょうか。
- 中式错误：问题就是手工太多，对吧。
- 更自然：課題としては / 手作業が多く確認漏れが発生しやすい点という理解でよろしいでしょうか。

### 具体例を一ついただけますでしょうか。
- 中文：请对方给一个具体例子。
- 场景：把抽象描述落到实际业务案例。
- SAP 例句：差し支えなければ / 具体例を一ついただけますでしょうか。
- 中式错误：例えばをください。
- 更自然：具体例を一つ / いただけますでしょうか。

## 4. 高频词汇

| 日语 | 读音 | 中文 | SAP 使用场景 | 错误提醒 |
|---|---|---|---|---|
| 現行業務 | げんこうぎょうむ | As-Is业务 | 需求访谈、流程整理、Fit-Gap | 不要直接说“今の仕事”，项目中用現行業務更稳。 |
| 業務要件 | ぎょうむようけん | 业务需求 | 需求定义、设计确认 | 要和系统功能要求区分。 |
| 課題／痛点 | かだい／つうてん | 痛点 | 问题整理、改善主题 | 日语会议里常用課題，痛点可解释为困りごと。 |
| 例外処理 | れいがいしょり | 例外处理 | 审批、月结、手工补正 | 不要只记录例外，要问发生条件。 |
| 承認ルート | しょうにんルート | 审批路线 | 权限、流程、控制点 | 要问部门、角色、金额条件。 |
| 頻度 | ひんど | 频率 | 需求优先级、影响判断 | 没有频率就难判断改善价值。 |
| 影響範囲 | えいきょうはんい | 影响范围 | 流程、部门、数据、月结 | 避免只问“困りますか”。 |
| 期待改善 | きたいかいぜん | 期待改善 | To-Be方向 | 不要提前承诺系统一定能实现。 |

## 5. 课后作业

- 主作业：设计10个SAP需求访谈问题，覆盖现行流程、痛点、例外、审批、报表。
- 录音作业：录 1 分钟，必须包含本课五步结构。
- 五步结构：現行業務を聞く → 発生条件を確認する → 頻度と対象を聞く → 影響を確認する → 課題理解を復唱する
- 提交前自查：是否说清对象、动作、确认路径、下一步。

## 1. 热身：硬指标跟读

请学生逐句跟读，第二遍加入 `/` 停顿。

- 現行業務では / どのように処理されていますか。
- 月次締めの際に / どの作業に最も時間がかかっていますか。
- 例外処理が発生する条件を / 教えていただけますでしょうか。
- 課題としては / 手作業が多く確認漏れが発生しやすいという理解でよろしいでしょうか。
- 具体例を一つ / いただけますでしょうか。

## 2. 填空练习

- 句型：`現行業務では、どのように処理されていますか。`
  - 填空：______ / 現行業務では / どのように処理されていますか。
  - 替换任务：询问现行月结差异调整流程。
- 句型：`〜の場合は、どの部署が承認しますか。`
  - 填空：______ / 差異がある場合は / どの部署で承認されますか。
  - 替换任务：询问供应商主数据变更由谁审批。
- 句型：`課題としては〜という理解でよろしいでしょうか。`
  - 填空：______ / 課題としては / 手作業が多く確認漏れが発生しやすい点という理解でよろしいでしょうか。
  - 替换任务：确认“审批路线不清导致延迟”这一痛点。
- 句型：`具体例を一ついただけますでしょうか。`
  - 填空：______ / 具体例を一つ / いただけますでしょうか。
  - 替换任务：请客户给一个例外处理案例。

## 3. 改错练习

- 错误：今はどうやっていますか。
- 改法：現行業務では / どのように処理されていますか。

- 错误：この時、誰がOKしますか。
- 改法：差異がある場合は / どの部署で承認されますか。

- 错误：问题就是手工太多，对吧。
- 改法：課題としては / 手作業が多く確認漏れが発生しやすい点という理解でよろしいでしょうか。

- 错误：例えばをください。
- 改法：具体例を一つ / いただけますでしょうか。

## 4. 课堂互动

需求访谈五问：When/Who/What/Frequency/Impact，用日语逐轮追问。

## 5. Roleplay

| 角色 | 任务 | 必须说出的内容 |
|---|---|---|
| PM / 主持人 | 控制会议方向 | 本页目的、确认事项、下一步 |
| 模块顾问 | 说明自己负责范围 | 模块、对象、风险、确认路径 |
| 客户侧用户 | 提出追问 | 资料、期限、责任人 |
| PMO / 协作团队 | 补充路径 | 课题管理、升级路线、记录方式 |

## 6. 小测

1. 听一句，写出责任主体。
2. 读一句，加入停顿。
3. 换一句，换成自己的模块。
4. 改一句，把中式表达改自然。
5. 说一句，补上下一步。

# Lesson 24 v4 课堂练习与 Roleplay

## 1. 热身：硬指标跟读

请学生逐句跟读，第二遍加入 `/` 停顿。

- ご迷惑をおかけし / 申し訳ございません。
- 設定変更の影響で / 一部伝票が正常に転記されませんでした。
- 原因は現在確認中です。
- 現時点での影響範囲は / 5月分の請求データのみです。
- 再発防止策として / 変更前チェックリストとレビュー手順を追加いたします。

## 2. 填空练习

- 句型：`申し訳ございません。〜してしまいました。`
  - 填空：______ / ご迷惑をおかけし / 申し訳ございません。〜してしまいました。
  - 替换任务：说明配置错误导致测试异常。
- 句型：`原因は現在確認中です。`
  - 填空：______ / 原因は現在確認中です。確認でき次第 / ご報告いたします。
  - 替换任务：原因未明时汇报。
- 句型：`影響範囲は〜です。`
  - 填空：______ / 現時点での影響範囲は / 〜です。
  - 替换任务：说明只影响测试环境。
- 句型：`再発防止策として〜を実施します。`
  - 填空：______ / 再発防止策として / チェックリストとレビュー手順を追加いたします。
  - 替换任务：说明增加双人review。

## 3. 改错练习

- 错误：すみません、ミスしました。
- 改法：ご迷惑をおかけし / 申し訳ございません。〜してしまいました。

- 错误：たぶん設定ミスです。
- 改法：原因は現在確認中です。確認でき次第 / ご報告いたします。

- 错误：影響は少しあります。
- 改法：現時点での影響範囲は / 〜です。

- 错误：次から気をつけます。
- 改法：再発防止策として / チェックリストとレビュー手順を追加いたします。

## 4. 课堂互动

紧急汇报1分钟演练：不能解释过多，必须按“謝罪→事実→影響→対応→次回報告”顺序。

## 5. Roleplay

| 角色 | 任务 | 必须说出的内容 |
|---|---|---|
| PM / 主持人 | 控制会议方向 | 本页目的、确认事项、下一步 |
| 模块顾问 | 说明自己负责范围 | 模块、对象、风险、确认路径 |
| 客户侧用户 | 提出追问 | 资料、期限、责任人 |
| PMO / 协作团队 | 补充路径 | 课题管理、升级路线、记录方式 |

## 6. 小测

1. 听一句，写出责任主体。
2. 读一句，加入停顿。
3. 换一句，换成自己的模块。
4. 改一句，把中式表达改自然。
5. 说一句，补上下一步。

## S-Slide 01：课程标题：严谨细致与责任担当文化

### 页面展示内容
- Lesson 02：“严谨细致”与“责任担当”文化
- SAP 项目现场训练：测试差异出现时，顾问如何说明事实、范围、未确认事项和下一步。

### 学习重点
本课不是普通日本文化课，而是把“细节、记录、期限、担当”训练成 SAP 项目初报能力。

### SAP 项目例句
本件については、私の方で確認いたします。

### 学生练习
用中文说一个你在测试、配置或接口联调中遇到过的“原因还不能断定”的场景。

## S-Slide 02：这节课解决什么 SAP 项目风险

### 页面展示内容
- 测试中发现差异。原因可能来自主数据、配置、接口或用户操作。
- 顾问必须说明：事实、确认済み、未确认、担当范围、反馈期限。

### 学习重点
避免“我以为、应该可以、差不多、后面再说”这类会损害专业信任的表达。

### SAP 项目例句
現時点では、再現条件まで確認できております。

### 学生练习
把“应该是用户操作问题”改成更稳妥的中文项目表达。

## S-Slide 05：本课硬指标 5 句

### 页面展示内容
- 1. 本件については、私の方で確認いたします。
- 2. 明日17時までに一次回答を行う予定です。
- 3. 現時点では、再現条件まで確認できております。
- 4. 未確認事項として、課題管理表で管理いたします。
- 5. 担当範囲としては、設定確認とテスト証跡の整理まで対応いたします。

### 学习重点
这 5 句是 Lesson 02 的最低达标线，必须能带停顿读出来。

### SAP 项目例句
担当範囲としては、設定確認とテスト証跡の整理まで対応いたします。

### 学生练习
每人选一句读两遍，第二遍必须加停顿。

## S-Slide 06：主场景：测试差异初报

### 页面展示内容
- 场景：测试中发现差异。
- 可能原因：主数据 / 配置 / 接口 / 用户操作。
- 要求：说明事实、确认済み、未确认、下一步、期限。

### 学习重点
原因未确定时，先做“初报”，不要做“结论报告”。

### SAP 项目例句
現時点では原因を断定できません。まず再現条件を確認いたします。

### 学生练习
把一个差异场景拆成：现象 / 可能原因 / 先确认什么。

## S-Slide 07：为什么日本项目重视证据和记录

### 页面展示内容
- 不是形式主义：证据用于对齐事实。
- 记录用于防止认知偏差。
- 期限用于保护项目节奏。

### 学习重点
把“细致”翻译成项目管理动作：证迹、记录、课题管理、期限。

### SAP 项目例句
確認結果と証跡は、課題管理表に添付いたします。

### 学生练习
说出一个没有证迹会导致返工的 SAP 测试场景。

## S-Slide 08：严谨细致在 SAP 项目中的实际含义

### 页面展示内容
- 现象：准确描述
- 影响：限定范围
- 证迹：可复核
- 原因：不提前断定
- 期限：明确下一次反馈

### 学习重点
严谨不是说话慢，而是每个判断都有边界。

### SAP 项目例句
影響範囲は、現時点ではテストデータ3件のみ確認できております。

### 学生练习
把“影响很大”改成有范围的表达。

## S-Slide 09：责任担当不是全部自己背锅

### 页面展示内容
- 担当：明确自己负责的动作
- 协作：明确需要谁一起确认
- 管理：未确认事项进入课题管理表
- 承诺：只承诺可控范围和下一步

### 学习重点
责任担当是“管理到位”，不是“马上给结论”。

### SAP 项目例句
FI側の設定影響については、私の方で確認いたします。COチームとの確認が必要な点は、未確認事項として管理いたします。

### 学生练习
把“我负责全部确认”改成“我负责 A，同时需要 B 协作”。

## S-Slide 10：五步汇报结构：现象、影响、确认済み、未确认、次回报告

### 页面展示内容
- 1. 現象：发生了什么
- 2. 影響：影响范围到哪里
- 3. 確認済み：已经确认到哪里
- 4. 未確認：还没确认什么
- 5. 次回報告：什么时候给下一次结果

### 学习重点
任何测试差异初报都可以先按这 5 步讲。

### SAP 项目例句
現象としては、請求テストで金額差異が発生しております。現時点では、再現条件まで確認できております。

### 学生练习
用中文按 5 步说一个 30 秒初报。

## S-Slide 11：高频词汇 1：担当範囲 / 未決事項

### 页面展示内容
- 担当範囲（たんとうはんい）：责任范围
- 未決事項（みけつじこう）：未决事项

### 学习重点
这两个词用于说明“我负责什么”和“还没定什么”。

### SAP 项目例句
担当範囲としては、設定確認とテスト証跡の整理まで対応いたします。

### 学生练习
把“我负责确认配置”改成包含 `担当範囲` 的日语。

## S-Slide 12：高频词汇 2：課題管理表 / 証跡 / 期限厳守

### 页面展示内容
- 課題管理表（かだいかんりひょう）：问题管理表
- 証跡（しょうせき）：证据 / 测试证迹
- 期限厳守（きげんげんしゅ）：严守期限

### 学习重点
这三个词用于把问题推进变成可追踪动作。

### SAP 项目例句
未確認事項は、課題管理表で管理し、証跡を添付いたします。

### 学生练习
用这三个词造一个测试问题跟进句。

## S-Slide 13：句型 1：〜については、私の方で確認いたします

### 页面展示内容
- 用于承担可控范围内的确认动作。
- 结构：对象 + については、私の方で確認いたします。

### 学习重点
主动承担，但不扩大到不可控结论。

### SAP 项目例句
FI側の設定影響については、私の方で確認いたします。

### 学生练习
替换对象：主数据 / 配置 / 接口日志 / 权限角色 / 测试证迹。

## S-Slide 14：句型 1 替换练习：对象要具体

### 页面展示内容
- 主データ / 設定影響 / インターフェースログ / 権限ロール / テスト証跡
- 不要只换模块名，要换“可确认对象”。

### 学习重点
从“我负责 FI”升级为“我负责 FI 侧设置影响确认”。

### SAP 项目例句
権限ロールの設定については、Basis側とも確認いたします。

### 学生练习
写 3 句：一个自己确认，一个和他团队确认，一个只做未确认管理。

## S-Slide 15：句型 2：〜までに対応予定です

### 页面展示内容
- 用于说明下一步期限。
- 结构：时间 + までに + 动作 + 予定です。
- 更稳：一次回答 / 確認結果 / 対応方針 を提示する。

### 学习重点
不要只说“尽快”，要给可管理的下一次输出。

### SAP 项目例句
明日17時までに、一次回答を行う予定です。

### 学生练习
替换期限：本日中 / 明日17時 / 次回定例会 / 金曜日午前。

## S-Slide 16：期限表达的安全边界

### 页面展示内容
- 安全承诺：一次回答、确认结果、调查方针、证迹整理
- 高风险承诺：一定修好、原因确定、全部解决、今天就关闭

### 学习重点
能承诺推进，不要轻易承诺最终结果。

### SAP 项目例句
本日中に解決とはお約束できませんが、明日17時までに一次回答を行う予定です。

### 学生练习
把“今天一定解决”改成稳妥表达。

## S-Slide 17：句型 3：現時点では〜まで確認できております

### 页面展示内容
- 用于说明已经确认到哪里。
- 结构：現時点では + 对象/范围 + まで確認できております。

### 学习重点
把“已确认”和“未确认”分开。

### SAP 项目例句
現時点では、再現条件と対象データ3件まで確認できております。

### 学生练习
替换确认范围：再现条件 / 3 件数据 / 配置项目 / 日志时间带。

## S-Slide 18：句型 4：未確認事項として管理いたします

### 页面展示内容
- 用于说明还没确认的内容如何管理。
- 结构：对象 + は、未確認事項として管理いたします。
- 常搭配：課題管理表 / 関係チーム確認 / 次回報告

### 学习重点
未确认不是忘记，也不是推脱，而是进入管理。

### SAP 项目例句
インターフェースログの確認は、未確認事項として課題管理表で管理いたします。

### 学生练习
把“这个还没看”改成正式未确认管理表达。

## S-Slide 19：中式表达风险：我以为、应该、差不多

### 页面展示内容
- 我以为：認識していました / 思っていました
- 应该可以：おそらくできます
- 差不多：だいたい大丈夫です
- 后面再说：後で確認します

### 学习重点
这些表达会让客户觉得边界不清、责任不清、期限不清。

### SAP 项目例句
推測ではなく、確認できている範囲でご説明いたします。

### 学生练习
把 4 个中式表达改成项目现场可用日语。

## S-Slide 20：标准对话：测试差异初报

### 页面展示内容
- 客户：原因は分かりましたか。今日中に直せますか。
- 顾问：现象、确认済み、未确认、担当范围、期限を順番に説明。

### 学习重点
标准版是背诵基准，先不追求自由发挥。

### SAP 项目例句
本件については、私の方で確認いたします。現時点では、再現条件まで確認できております。

### 学生练习
标出对话中的 5 个功能句。

## S-Slide 21：对话逐句拆解：每一句都有项目功能

### 页面展示内容
- 接收问题：本件については...
- 事实边界：現時点では...
- 切分方向：〜の観点で...
- 未决管理：未確認事項として...
- 期限输出：〜までに一次回答...

### 学习重点
背句子时要同时背功能。

### SAP 项目例句
原因については、各観点で切り分けて確認中です。

### 学生练习
把每一句旁边写上“功能标签”。

## S-Slide 22：慢速领读版：按意图块停顿

### 页面展示内容
- 本件については / 私の方で / 確認いたします。
- 現時点では / 再現条件まで / 確認できております。
- 未確認事項として / 課題管理表で / 管理いたします。

### 学习重点
停顿不是语法装饰，而是让听的人跟得上你的逻辑。

### SAP 项目例句
明日17時までに / 一次回答を行う予定です。

### 学生练习
全班跟读两轮，第二轮隐藏中文。

## S-Slide 24：中式错误版：找出 5 个风险

### 页面展示内容
- たぶん設定の問題です。
- 今日中に全部直します。
- まだ見ていません。
- ユーザーが間違いました。
- 後で確認します。

### 学习重点
找出：提前断定、过度承诺、没有管理、归责过硬、期限不清。

### SAP 项目例句
現時点では原因を断定できません。まず再現条件を確認いたします。

### 学生练习
把 5 个错误句改成项目现场可用表达。

## S-Slide 25：高级自然版：短、稳、有边界

### 页面展示内容
- 現時点では原因を断定せず、まず再現条件と証跡を整理いたします。
- 設定影響については私の方で確認し、他チーム確認が必要な点は未確認事項として管理いたします。
- 明日17時までに一次回答いたします。

### 学习重点
高级不是更长，而是更短、更稳、更有边界。

### SAP 项目例句
現時点では原因を断定せず、確認できている範囲でご説明いたします。

### 学生练习
把标准版压缩成 3 句高级版。

## S-Slide 26：模块替换：FICO / MM / SD / Basis / ABAP-BTP

### 页面展示内容
- FICO：会社コード設定、会計伝票、金額差異
- MM：購買条件、仕入先マスタ、入庫差異
- SD：請求データ、価格条件、売上計上
- Basis：権限ロール、ジョブ、接続
- ABAP-BTP：API連携、ログ、拡張影響

### 学习重点
同一型可迁移，替换的是对象、团队、证迹和期限。

### SAP 项目例句
API連携ログについては、開発チームとも確認し、未確認事項として管理いたします。

### 学生练习
每人选自己模块做 30 秒初报。

## S-Slide 27：Roleplay：客户追问原因与期限

### 页面展示内容
- A 客户：原因は分かりましたか。今日中に直せますか。
- B 顾问：按五步初报，不能提前断定，不能乱承诺。
- C 观察者：检查事实、未确认、担当、期限。

### 学习重点
在压力下保持边界清楚。

### SAP 项目例句
本日中に解決とはお約束できませんが、明日17時までに一次回答いたします。

### 学生练习
三人一组 Roleplay：客户、顾问、观察者。

## S-Slide 28：1 分钟录音作业与自我检查

### 页面展示内容
- 用日语做 1 分钟“问题初报”。
- 必须包含：現象、影響、確認済み、未確認、次回報告予定。
- 讲师只批改：最影响专业感、最影响理解、最常反复出现的中式日语。

### 学习重点
能录出来，才说明能在会议中开口。

### SAP 项目例句
現象としては、請求テストで金額差異が発生しております。明日17時までに一次回答いたします。

### 学生练习
当场用中文列 5 点，课后录日语 1 分钟。

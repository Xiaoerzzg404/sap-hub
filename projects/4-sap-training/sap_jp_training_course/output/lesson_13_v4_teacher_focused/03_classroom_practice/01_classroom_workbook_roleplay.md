# Lesson 13 v4 课堂练习与 Roleplay

## 1. 热身：硬指标跟读

请学生逐句跟读，第二遍加入 `/` 停顿。

- 要件定義は / 支援を受けながら対応できるレベルです。
- 日本プロジェクトでは / 業務理解とドキュメント作成力が求められます。
- 会議では / 不明点を早めに確認することを期待されています。
- 今後は / ファシリテーション力を強化したいと考えています。
- 不明点をそのままにせず / 早めに確認する姿勢を大切にしています。

## 2. 填空练习

- 句型：`〜できるレベルです。`
  - 填空：______ / 基本設計書は / レビューを受けながら作成できるレベルです。
  - 替换任务：说明“测试执行可以独立做，设计需要review”。
- 句型：`〜が求められます。`
  - 填空：______ / 日本プロジェクトでは / 正確なドキュメント作成力が求められます。
  - 替换任务：说一个你认为日本项目要求的能力。
- 句型：`〜を期待されています。`
  - 填空：______ / このポジションでは / 課題を早めに共有することを期待されています。
  - 替换任务：说出 PM 对顾问的一项期待。
- 句型：`今後は〜を強化したいと考えています。`
  - 填空：______ / 今後は / 会議でのファシリテーション力を強化したいと考えています。
  - 替换任务：把“我以后加强日语”说具体。

## 3. 改错练习

- 错误：私は基本設計ができます。
- 改法：基本設計書は / レビューを受けながら作成できるレベルです。

- 错误：日本项目要求我做文件。
- 改法：日本プロジェクトでは / 正確なドキュメント作成力が求められます。

- 错误：みんなは私に期待します。
- 改法：このポジションでは / 課題を早めに共有することを期待されています。

- 错误：私はこれからもっと頑張ります。
- 改法：今後は / 会議でのファシリテーション力を強化したいと考えています。

## 4. 课堂互动

能力矩阵自评：语言、模块、文档、会议、客户沟通各1-5分，用日语说改善计划。

## 5. Roleplay

| 角色 | 任务 | 必须说出的内容 |
|---|---|---|
| PM / 主持人 | 控制会议方向 | 本页目的、确认事项、下一步 |
| 模块顾问 | 说明自己负责范围 | 模块、对象、风险、确认路径 |
| 客户侧用户 | 提出追问 | 资料、期限、责任人 |
| PMO / 协作团队 | 补充路径 | 课题管理、升级路线、记录方式 |

## 6. 小测

1. 听一句，写出责任主体。
2. 读一句，加入停顿。
3. 换一句，换成自己的模块。
4. 改一句，把中式表达改自然。
5. 说一句，补上下一步。

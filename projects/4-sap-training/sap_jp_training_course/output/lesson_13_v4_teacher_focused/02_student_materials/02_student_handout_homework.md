# Lesson 13 v4 学生讲义与课后作业

updated_by: codex
updated_at: 2026-05-18T09:59:16+09:00

## 1. 本课主场景

顾问向日本PM说明自己的能力边界：哪些能独立做，哪些需要review，怎样保证质量。

## 2. 硬指标 5 句

1. 要件定義は / 支援を受けながら対応できるレベルです。
2. 日本プロジェクトでは / 業務理解とドキュメント作成力が求められます。
3. 会議では / 不明点を早めに確認することを期待されています。
4. 今後は / ファシリテーション力を強化したいと考えています。
5. 不明点をそのままにせず / 早めに確認する姿勢を大切にしています。

## 3. 核心句型速查

### 〜できるレベルです。
- 中文：说明自己能做到什么程度。
- 场景：面试、参画前能力确认、任务分配前说明边界。
- SAP 例句：基本設計書は / レビューを受けながら作成できるレベルです。
- 中式错误：私は基本設計ができます。
- 更自然：基本設計書は / レビューを受けながら作成できるレベルです。

### 〜が求められます。
- 中文：某场景需要某能力。
- 场景：说明日本项目要求、团队期待、岗位标准。
- SAP 例句：要件定義では / 業務理解だけでなく議事録や課題整理の力も求められます。
- 中式错误：日本项目要求我做文件。
- 更自然：日本プロジェクトでは / 正確なドキュメント作成力が求められます。

### 〜を期待されています。
- 中文：被期待承担某种表现或结果。
- 场景：说明团队对自己角色的期待。
- SAP 例句：会議では / 不明点を早めに確認することを期待されています。
- 中式错误：みんなは私に期待します。
- 更自然：このポジションでは / 課題を早めに共有することを期待されています。

### 今後は〜を強化したいと考えています。
- 中文：今后想加强某能力。
- 场景：面试回答弱点、学习计划、成长路线。
- SAP 例句：今後は / ファシリテーション力を強化したいと考えています。
- 中式错误：私はこれからもっと頑張ります。
- 更自然：今後は / 会議でのファシリテーション力を強化したいと考えています。

## 4. 高频词汇

| 日语 | 读音 | 中文 | SAP 使用场景 | 错误提醒 |
|---|---|---|---|---|
| 即戦力 | そくせんりょく | 即战力 | 说明参画后能较快承担任务 | 不要自称“完全即戦力”，要说明具体可独立范围。 |
| 業務理解 | ぎょうむりかい | 业务理解 | 要件定义、测试场景、客户沟通 | 不要只说懂SAP，要说懂业务流程。 |
| コミュニケーション力 | コミュニケーションりょく | 沟通能力 | 会议确认、课题升级、跨团队协作 | 不只是会说日语，也包括确认和留证据。 |
| ドキュメント作成力 | ドキュメントさくせいりょく | 文档能力 | 议事录、设计书、测试证据、课题整理 | 日本项目里文档能力常被直接评价。 |
| 主体性 | しゅたいせい | 主动性 | 发现问题、提前确认、推动下一步 | 不是擅自决定，而是主动确认。 |
| 品質担保 | ひんしつたんぽ | 质量保证 | review、检查清单、证据留存 | 不要只说“品質がいい”，要说方法。 |
| 期限遵守 | きげんじゅんしゅ | 遵守期限 | 任务、交付物、会议回复 | 延迟时要提前共有风险。 |
| 改善計画 | かいぜんけいかく | 改善计划 | 面试弱点说明和成长路线 | 不要只说努力，要有具体动作。 |

## 5. 课后作业

- 主作业：准备一段面试回答：“あなたの強みと今後の課題を教えてください”。
- 录音作业：录 1 分钟，必须包含本课五步结构。
- 五步结构：できる範囲を言う → レビューが必要な範囲を言う → 品質担保の方法を言う → 求められる力を理解する → 今後の強化点を言う
- 提交前自查：是否说清对象、动作、确认路径、下一步。

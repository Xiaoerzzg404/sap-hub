## 2. 必背 10 句

1. 承知しました。/ まず前提を確認させてください。
2. その対応は / 二日以内では難しい可能性がございます。
3. 一点懸念として / 他モジュールへの影響確認が必要です。
4. 念のため / 優先順位を確認させてください。
5. 月次締め前に必ず承認を完了したい / という理解でよろしいでしょうか。
6. 代替案としては / 段階的な対応が考えられます。
7. まずは暫定対応を行い / 恒久対応は別途検討いたします。
8. 認識相違がございましたら / ご指摘ください。
9. 影響範囲を整理したうえで / 対応方針をご提案いたします。
10. 本日中に / 優先度と影響範囲を整理いたします。

## 3. 对话 5 版本

### 3.1 标准版

```text
お客様：二日以内にこの跨モジュール変更を本番反映できますか。
顧問：承知しました。/ 念のため前提を確認させてください。
顧問：その対応は二日以内では難しい可能性がございます。
顧問：一点懸念として他モジュールへの影響確認とテスト範囲の確認が必要です。
顧問：代替案としてはまず暫定対応を行い、恒久対応は次フェーズで検討する形が考えられます。
```

## 5. 中式日语踩坑 Top5

1. `無理です。` -> 直接否定，关系和讨论都容易断掉 -> `難しい可能性がございます。`
2. `違います。` -> 直接指出对方错 -> `認識相違がないよう確認させてください。`
3. `分かりません。` -> 信息不足且被动 -> `現時点では判断できないため、影響範囲を確認いたします。`
4. `問題があります。` -> 过硬且不具体 -> `一点懸念として、テスト範囲の確認が必要です。`
5. `できないです。` -> 没有替代方案 -> `代替案として段階的な対応が考えられます。`

## 7. 日语自然度复核

- 不要为了礼貌把句子拉得过长。
- 项目现场优先保证对象、动作、下一步清楚。
- 学生水平低时，先用标准版；高级顾问再练高级自然版。
- 如果表达涉及客户动作，注意尊敬/请求语气；涉及自己动作，注意自谦或丁宁。

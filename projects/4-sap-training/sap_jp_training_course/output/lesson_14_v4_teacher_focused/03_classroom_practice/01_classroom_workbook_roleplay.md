## 1. 热身：硬指标跟读

请学生逐句跟读，第二遍加入 `/` 停顿。

- 本日は / キックオフとしてプロジェクトの目的とスコープについてご説明いたします。
- 本プロジェクトの目的は / 現行業務を整理し標準化の方針を確認することです。
- FI領域は / 弊社が担当するという体制で進めてまいります。
- 次回までに / 現行業務フローのご共有をお願いいたします。
- 本日は / 役割分担と今後の進め方を確認いたします。

## 2. 填空练习

- 句型：`本日は〜についてご説明いたします。`
  - 填空：______ / 本日は / プロジェクトの目的と進め方についてご説明いたします。
  - 替换任务：把“今天说明FI范围”改成正式日语。
- 句型：`本プロジェクトの目的は〜です。`
  - 填空：______ / 本プロジェクトの目的は / 業務プロセスを整理し、SAP標準とのFitを確認することです。
  - 替换任务：说出一个项目目标，不要只说“导入SAP”。
- 句型：`〜という体制で進めてまいります。`
  - 填空：______ / FI領域は弊社が担当し / マスタ移行はお客様側と連携するという体制で進めてまいります。
  - 替换任务：用自己的模块说体制。
- 句型：`次回までに〜をお願いいたします。`
  - 填空：______ / 次回会議までに / 現行業務フローをご共有いただけますでしょうか。
  - 替换任务：请求客户下次前提供科目表。

## 3. 改错练习

- 错误：今日はこれを説明します。
- 改法：本日は / プロジェクトの目的と進め方についてご説明いたします。

- 错误：このプロジェクトはSAPを入れます。
- 改法：本プロジェクトの目的は / 業務プロセスを整理し、SAP標準とのFitを確認することです。

- 错误：我们负责FI，客户负责主数据。
- 改法：FI領域は弊社が担当し / マスタ移行はお客様側と連携するという体制で進めてまいります。

- 错误：次までに出してください。
- 改法：次回会議までに / 現行業務フローをご共有いただけますでしょうか。

## 4. 课堂互动

5分钟模拟Kickoff：主持人、PM、FI顾问、业务用户四个角色轮流发言。

## 5. Roleplay

| 角色 | 任务 | 必须说出的内容 |
|---|---|---|
| PM / 主持人 | 控制会议方向 | 本页目的、确认事项、下一步 |
| 模块顾问 | 说明自己负责范围 | 模块、对象、风险、确认路径 |
| 客户侧用户 | 提出追问 | 资料、期限、责任人 |
| PMO / 协作团队 | 补充路径 | 课题管理、升级路线、记录方式 |

## 6. 小测

1. 听一句，写出责任主体。
2. 读一句，加入停顿。
3. 换一句，换成自己的模块。
4. 改一句，把中式表达改自然。
5. 说一句，补上下一步。

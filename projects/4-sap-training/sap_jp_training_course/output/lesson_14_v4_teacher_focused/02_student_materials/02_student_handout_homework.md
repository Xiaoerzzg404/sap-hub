# Lesson 14 v4 学生讲义与课后作业

updated_by: codex
updated_at: 2026-05-18T09:59:16+09:00

## 1. 本课主场景

作为FI顾问参加Kickoff，向客户说明自己负责范围和本周需要客户提供的资料。

## 2. 硬指标 5 句

1. 本日は / キックオフとしてプロジェクトの目的とスコープについてご説明いたします。
2. 本プロジェクトの目的は / 現行業務を整理し標準化の方針を確認することです。
3. FI領域は / 弊社が担当するという体制で進めてまいります。
4. 次回までに / 現行業務フローのご共有をお願いいたします。
5. 本日は / 役割分担と今後の進め方を確認いたします。

## 3. 核心句型速查

### 本日は〜についてご説明いたします。
- 中文：今天将说明某个议题。
- 场景：会议开场、说明议程、切入主题。
- SAP 例句：本日は / キックオフとしてプロジェクトの目的、スコープ、体制についてご説明いたします。
- 中式错误：今日はこれを説明します。
- 更自然：本日は / プロジェクトの目的と進め方についてご説明いたします。

### 本プロジェクトの目的は〜です。
- 中文：说明项目目标。
- 场景：Kickoff、范围确认、客户沟通。
- SAP 例句：本プロジェクトの目的は / 現行業務を整理し標準化の方針を確認することです。
- 中式错误：このプロジェクトはSAPを入れます。
- 更自然：本プロジェクトの目的は / 業務プロセスを整理し、SAP標準とのFitを確認することです。

### 〜という体制で進めてまいります。
- 中文：以某种项目体制推进。
- 场景：说明角色分工、供应商/客户协作方式。
- SAP 例句：FI領域は弊社が担当し / マスタ移行はお客様側と連携するという体制で進めてまいります。
- 中式错误：我们负责FI，客户负责主数据。
- 更自然：FI領域は弊社が担当し / マスタ移行はお客様側と連携するという体制で進めてまいります。

### 次回までに〜をお願いいたします。
- 中文：请在下次会议前准备/提供某物。
- 场景：会议结束、资料请求、下一步确认。
- SAP 例句：次回会議までに / 現行業務フローのご共有をお願いいたします。
- 中式错误：次までに出してください。
- 更自然：次回会議までに / 現行業務フローをご共有いただけますでしょうか。

## 4. 高频词汇

| 日语 | 读音 | 中文 | SAP 使用场景 | 错误提醒 |
|---|---|---|---|---|
| キックオフ | キックオフ | 启动会 | 项目开始时统一目标、范围、体制和规则 | 不要只当作自我介绍会。 |
| 目的 | もくてき | 目标 | 说明项目为什么做、要达成什么 | 目标要比“导入系统”更具体。 |
| スコープ | スコープ | 范围 | 说明本项目包含/不包含的业务和系统范围 | 范围不清会导致追加需求争议。 |
| 役割分担 | やくわりぶんたん | 角色分工 | 说明客户、供应商、PMO、模块顾问职责 | 不要只说名字，要说负责事项。 |
| 進め方 | すすめかた | 推进方式 | 会议节奏、资料提供、课题管理、确认路径 | 推进方式要落到下一步。 |
| 現行業務フロー | げんこうぎょうむフロー | 现行业务流程 | 需求调研和Fit-Gap前的基础资料 | 请求资料时要说明用途。 |
| 体制 | たいせい | 项目体制 | 团队结构、汇报路线、责任分担 | 不要和制度混淆。 |
| 次回会議 | じかいかいぎ | 下次会议 | 结束前确认动作和期限 | 必须明确“谁在什么时候做什么”。 |

## 5. 课后作业

- 主作业：写一份Kickoff发言稿，包含开场、目标、范围、角色、下一步。
- 录音作业：录 1 分钟，必须包含本课五步结构。
- 五步结构：本日の目的を言う → プロジェクト目的を言う → スコープを言う → 体制と役割を言う → 次回までの依頼を言う
- 提交前自查：是否说清对象、动作、确认路径、下一步。

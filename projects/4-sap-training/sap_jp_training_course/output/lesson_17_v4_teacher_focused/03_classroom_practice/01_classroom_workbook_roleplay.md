## 1. 热身：硬指标跟读

请学生逐句跟读，第二遍加入 `/` 停顿。

- 開発環境の設定を / 検証環境へ移送していただけますでしょうか。
- ユーザーに必要な権限が / 不足している可能性があります。
- 夜間ジョブが正常終了しているか / ご確認をお願いいたします。
- 設定が検証環境に / 反映されていますか。
- 対象クライアントとユーザーIDを / 共有いたします。

## 2. 填空练习

- 句型：`〜を移送していただけますでしょうか。`
  - 填空：______ / 開発環境の設定を / 検証環境へ移送していただけますでしょうか。
  - 替换任务：请求传输一个配置请求。
- 句型：`〜環境に反映されていますか。`
  - 填空：______ / 対象の移送依頼は / 検証環境に反映されていますか。
  - 替换任务：确认开发是否反映到QA。
- 句型：`〜権限が不足している可能性があります。`
  - 填空：______ / 対象ユーザーに / 必要な権限が不足している可能性があります。
  - 替换任务：说明过账权限不足。
- 句型：`ジョブの実行結果をご確認ください。`
  - 填空：______ / ジョブの実行結果を / ご確認いただけますでしょうか。
  - 替换任务：请求确认月结Job结果。

## 3. 改错练习

- 错误：これを運んでください。
- 改法：開発環境の設定を / 検証環境へ移送していただけますでしょうか。

- 错误：テストにありますか。
- 改法：対象の移送依頼は / 検証環境に反映されていますか。

- 错误：権限がないと思います。
- 改法：対象ユーザーに / 必要な権限が不足している可能性があります。

- 错误：ジョブを見てください。
- 改法：ジョブの実行結果を / ご確認いただけますでしょうか。

## 4. 课堂互动

请求票据写作：老师给现象，学生写给Basis的日语依赖内容。

## 5. Roleplay

| 角色 | 任务 | 必须说出的内容 |
|---|---|---|
| PM / 主持人 | 控制会议方向 | 本页目的、确认事项、下一步 |
| 模块顾问 | 说明自己负责范围 | 模块、对象、风险、确认路径 |
| 客户侧用户 | 提出追问 | 资料、期限、责任人 |
| PMO / 协作团队 | 补充路径 | 课题管理、升级路线、记录方式 |

## 6. 小测

1. 听一句，写出责任主体。
2. 读一句，加入停顿。
3. 换一句，换成自己的模块。
4. 改一句，把中式表达改自然。
5. 说一句，补上下一步。

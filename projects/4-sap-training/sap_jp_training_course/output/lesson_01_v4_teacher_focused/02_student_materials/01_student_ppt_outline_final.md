## S-Slide 01：课程标题

## S-Slide 02：这节课解决什么 SAP 项目痛点

### 页面展示内容
客户坚持：“现行业务不能改，SAP 也要照旧处理。”  
顾问不能直接说 `できません`，也不能当场承诺“可以照旧”。

### 学习重点
礼貌表达的目的，是让风险、前提和下一步被客户接受。

### SAP 项目例句
一点確認させてください。

### 学生练习
把“这个不行”改成更稳妥的中文表达。

## S-Slide 05：本课硬指标 5 句

### 页面展示内容
1. ご意向は理解いたしました。  
2. 一点確認させてください。  
3. 〇〇という理解でよろしいでしょうか。  
4. 〇〇の観点では、影響範囲を確認する必要があると考えております。

### 学习重点

## S-Slide 07：“和”文化不是迎合

### 页面展示内容
不是无限同意；不是不说风险；不是回避专业判断；不是现场承诺一切都可以。

### 学习重点
“和”是让讨论继续的表达技术。

### SAP 项目例句
業務背景は理解いたしました。

### 学生练习
说出“理解意向”和“同意方案”的区别。

## S-Slide 08：“和”文化在 SAP 项目中的实际含义

### 页面展示内容
尊重业务背景 → 确认前提 → 说明标准、统制、影响 → 给出下一步

### 学习重点
项目礼貌必须服务于交付。

### SAP 项目例句
前提条件を一点確認させてください。

### 学生练习

## S-Slide 09：核心结构：先认同 → 再确认 → 后建议

### 学习重点

### SAP 项目例句

### 学生练习

## S-Slide 15：句型 2：ご意向は理解いたしました

### 页面展示内容
理解客户意向，但不承诺方案。

### 学习重点
客户方案未确认前，默认使用这个表达。

### SAP 项目例句
ご意向は理解いたしました。一点確認させてください。

### 学生练习
把 `おっしゃる通りです` 换成更稳的表达。

## S-Slide 16：认同层级：不要滥用 おっしゃる通りです

### 页面展示内容
Level 1：内容は承知しました。  
Level 2：ご意向は理解いたしました。  
Level 3：おっしゃる通りです。

### 学习重点
`おっしゃる通りです` 只在事实或合理指摘明确成立时使用。

### SAP 项目例句
現行業務上の必要性は理解いたしました。

### 学生练习
判断 3 个场景该用哪个 Level。

## S-Slide 17：句型 3：〇〇の観点では

### 页面展示内容
用于表达专业保留：标准、统制、会计、权限、测试。

### 学习重点
让不同意见变成专业判断。

### SAP 项目例句
テスト範囲の観点では、影響範囲を確認する必要がございます。

### 学生练习
把角度换成 API 連携。

## S-Slide 18：句型 4：一度持ち帰って

### 页面展示内容

### 学习重点

### SAP 项目例句

### 学生练习

## S-Slide 19：三档表达：初级 / 标准 / 高级

### 页面展示内容
初级能说；标准可用；高级短而稳。

### 学习重点

### SAP 项目例句

### 学生练习

## S-Slide 25：中式错误版

### 页面展示内容

### 学习重点
找出承诺过快、否定过硬、请求太直接。

### SAP 项目例句

### 学生练习

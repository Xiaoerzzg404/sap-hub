# Lesson 01 学生讲义与作业包

updated_by: codex
updated_at: 2026-05-17T00:40:00+09:00

## 1. 本课学习目标

学完本课，你应该能够：

- 说明“和”文化在 SAP 项目中不是迎合客户，而是让讨论继续。
- 面对客户坚持现行流程时，用 3-5 句日语完成“先认同 → 再确认 → 后建议”。
- 不直接使用 `それは違います`、`できません`、`無理です`、`問題があります`。
- 用 `〇〇という理解でよろしいでしょうか` 确认前提和范围。
- 用 `〇〇の観点では` 表达专业保留。
- 完成 1 分钟录音作业。

## 2. 本课 SAP 项目主场景

| 项目 | 内容 |
|---|---|
| 主场景 | 客户坚持“现行业务不能改”，希望 SAP 也照旧处理。 |
| 推荐主案例 | FICO / SD-FI：客户希望承認前でも請求処理を進めたい。 |
| 顾问关注 | SAP 标准、会计连携、内部统制、权限、测试范围。 |
| 本课目标 | 不直接否定客户，也不现场乱承诺。 |

客户发言：

```text
現行業務ではこの流れで問題ありません。SAPでも同じように進めたいです。
```

## 3. 核心结构：先认同 → 再确认 → 后建议

```text
接住客户 → 理解意向 → 确认前提 → 表达专业保留 → 带回确认 → 下次说明
```

30 秒回应模板：

```text
ご意向は理解いたしました。一点確認させてください。
〇〇という理解でよろしいでしょうか。
〇〇の観点では、影響範囲を確認する必要があると考えております。
一度持ち帰って、確認のうえ次回ご説明いたします。
```

## 4. 硬指标 5 句

| No. | 日语 | 中文 | 替换点 |
|---:|---|---|---|
| 1 | ご意向は理解いたしました。 | 我理解您的意向。 | ご意向 / おっしゃる内容 / 業務背景 |
| 2 | 一点確認させてください。 | 请允许我确认一点。 | 一点 / 前提条件 / 対象範囲 |
| 3 | 〇〇という理解でよろしいでしょうか。 | 是否可以理解为〇〇？ | 会社コード / 販売組織 / 購買組織 / 権限ロール |
| 4 | 〇〇の観点では、影響範囲を確認する必要があると考えております。 | 从〇〇角度看，需要确认影响范围。 | SAP標準 / 内部統制 / 会計連携 / 権限管理 / テスト範囲 |

```text

```

## 7. 核心句型

### 句型 1：〇〇という理解でよろしいでしょうか

用于确认客户需求、范围、条件、例外。

例：

```text
全ての会社コードで同じ運用が必要という理解でよろしいでしょうか。
```

### 句型 2：ご意向は理解いたしました

用于理解客户意向，但不承诺方案。

例：

```text
ご意向は理解いたしました。一点確認させてください。
```

### 句型 3：〇〇の観点では

用于表达专业保留。

例：

```text
会計連携の観点では、影響範囲を確認する必要があると考えております。
```

### 句型 4：一度持ち帰って

用于说明带回确认和下一步。

例：

```text
一度持ち帰って、確認のうえ次回ご説明いたします。
```

## 8. 三档表达

| 功能 | 初级表达 | 标准表达 | 高级表达 |
|---|---|---|---|
| 接住客户 | 承知しました。 | 内容は承知しました。 | ご説明ありがとうございます。内容は承知いたしました。 |
| 理解意向 | 分かりました。 | ご意向は理解いたしました。 | 現行業務上の必要性は理解いたしました。 |
| 确认前提 | 確認します。 | 一点確認させてください。 | 前提条件を一点確認させてください。 |
| 确认范围 | これは全部ですか。 | 〇〇という理解でよろしいでしょうか。 | 対象範囲は〇〇まで、という理解でよろしいでしょうか。 |
| 请求背景 | 背景を教えてください。 | 差し支えなければ、背景をご教示いただけますでしょうか。 | 差し支えなければ、現行運用を継続されたい背景を確認させてください。 |
| 专业保留 | 確認が必要です。 | 〇〇の観点では、影響範囲を確認する必要があると考えております。 | SAP標準機能でどこまで対応できるか、影響範囲も含めて確認させてください。 |
| 带回确认 | 後で確認します。 | 一度持ち帰って確認いたします。 | 一度持ち帰って、関係チームにも確認いたします。 |
| 下次说明 | 次回話します。 | 次回ご説明いたします。 | 確認結果を整理し、次回の定例会でご説明いたします。 |

## 9. 中式日语踩坑 Top5

| NG | 风险 | OK |
|---|---|---|
| それは違います。 | 直接否定客户。 | ご意向は理解いたしました。一点確認させてください。 |
| できません。 | 只给否定，没有下一步。 | SAP標準機能でどこまで対応できるか確認いたします。 |
| 問題があります。 | 太笼统，像追责。 | 〇〇の観点では、リスクがある可能性がございます。 |
| 資料をください。 | 命令感强。 | 恐れ入りますが、〇〇をご共有いただけますでしょうか。 |
| 後で確認します。 | 时间、责任、输出不清。 | 一度持ち帰って、確認のうえ次回ご説明いたします。 |

## 10. 会前 3 分钟速查表

### 会前先写 5 个问题

1. 客户想保留的现行流程是什么？
2. 适用范围是什么？
3. 是常规运用还是例外运用？
4. 可能影响哪些模块？
5. 我不能现场承诺的点是什么？

### 会前准备 3 句

```text
ご意向は理解いたしました。
一点確認させてください。
〇〇の観点では、影響範囲を確認する必要があると考えております。
```

### 会前不要默认说

```text
それは違います。
できません。
無理です。
問題があります。
資料をください。
後で確認します。
```

## 11. 课堂对话复习

客户：

```text
現行業務ではこの流れで問題ありません。SAPでも同じように進めたいです。
```

顾问标准回应：

```text
ご意向は理解いたしました。一点確認させてください。
この運用は月末のみの例外対応という理解でよろしいでしょうか。
SAP標準および会計連携の観点では、影響範囲を確認する必要があると考えております。
一度持ち帰って、確認のうえ次回ご説明いたします。
```

## 12. 作业一：句型替换

用 `〇〇という理解でよろしいでしょうか` 改写：

1. 所有公司代码都适用。
2. 只针对总部采购。
3. 所有销售组织都适用。
4. 是临时权限付与。
5. 需要 API 连携的范围。

## 13. 作业二：中译日

1. 我理解现行业务上这样做的必要性。
2. 是否可以理解为，这个流程只在月末使用？
3. 从 SAP 标准功能角度看，希望先确认能支持到什么程度。
4. 如果方便的话，能否请您说明这个运用的背景？
5. 我会确认对相关模块的影响后，在下次例会上说明。

## 14. 作业三：SAP 场景回应

任选 FICO、MM、SD、Basis、ABAP-BTP 中一个模块，写 5-7 句日语回应。

场景：

```text
客户说：“现行业务一直这样做。SAP 上也请保持一样，不要改流程。”
```

回应必须包含：

- 理解客户业务背景；
- 至少 1 个确认前提的问题；
- 至少 1 个专业角度；
- 一个后续动作。

## 15. 作业四：1 分钟录音作业

客户说：

```text
現行業務ではこの流れで問題ありません。SAPでも同じように進めたいです。
```

请用日语录音 1 分钟回应。必须包含：

1. 理解客户业务背景；
2. 确认适用范围；
3. 从 `SAP標準 / 内部統制 / 会計連携 / 権限管理 / テスト範囲` 中任选一个角度表达保留；
4. 说明带回确认和下一步。

建议结构：

```text
ご意向は理解いたしました。
一点確認させてください。
〇〇という理解でよろしいでしょうか。
〇〇の観点では、影響範囲を確認する必要があると考えております。
一度持ち帰って、確認のうえ次回ご説明いたします。
```

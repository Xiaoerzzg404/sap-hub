## 1. 热身：硬指标跟读

请学生逐句跟读，第二遍加入 `/` 停顿。

- 支払条件を変更すると / 請求書の支払期日計算に影響します。
- 勘定設定は / MM側の入庫・請求書照合とFI転記に関係します。
- 設定後 / テスト伝票を登録して会計転記を確認します。
- 関連モジュールと / 整合性を取る必要があります。
- 設定値について / お客様側でご確認をお願いいたします。

## 2. 填空练习

- 句型：`〜を設定します／定義します。`
  - 填空：______ / 支払条件を設定します／定義します。
  - 替换任务：说明设置税码。
- 句型：`〜に影響します。`
  - 填空：______ / 支払条件を変更すると / 請求書の支払期日計算に影響します。
  - 替换任务：说明科目确定对会计凭证的影响。
- 句型：`〜と整合性を取る必要があります。`
  - 填空：______ / MM側の設定と / 整合性を取る必要があります。
  - 替换任务：说明 SD-FI 需要整合。
- 句型：`設定後、〜で確認します。`
  - 填空：______ / 設定後 / テスト伝票を登録して会計転記を確認します。
  - 替换任务：说明配置后用测试订单确认。

## 3. 改错练习

- 错误：これをセットします。
- 改法：支払条件を設定します／定義します。

- 错误：これを変えるといろいろ影響があります。
- 改法：支払条件を変更すると / 請求書の支払期日計算に影響します。

- 错误：MMと合わせなければなりません。
- 改法：MM側の設定と / 整合性を取る必要があります。

- 错误：設定した後で見ます。
- 改法：設定後 / テスト伝票を登録して会計転記を確認します。

## 4. 课堂互动

配置影响链练习：给一个配置项，学生说出影响模块、测试点、确认对象。

## 5. Roleplay

| 角色 | 任务 | 必须说出的内容 |
|---|---|---|
| PM / 主持人 | 控制会议方向 | 本页目的、确认事项、下一步 |
| 模块顾问 | 说明自己负责范围 | 模块、对象、风险、确认路径 |
| 客户侧用户 | 提出追问 | 资料、期限、责任人 |
| PMO / 协作团队 | 补充路径 | 课题管理、升级路线、记录方式 |

## 6. 小测

1. 听一句，写出责任主体。
2. 读一句，加入停顿。
3. 换一句，换成自己的模块。
4. 改一句，把中式表达改自然。
5. 说一句，补上下一步。

## 1. 本课主场景

向新参画成员说明客户系统架构：SAP、MES、WMS、E-commerce、会计报表系统如何连接。

## 2. 会前 3 分钟速查

1. 我现在处于哪一个项目场景？
2. 我需要说清哪个对象或角色？
3. 我需要使用哪一个核心句型？
4. 我的表达是否过硬、过轻或模糊？
5. 对方听完后是否知道下一步？

## 3. 本课硬指标 5 句

1. SAPは / 基幹システムとして / 受注から会計計上までのデータを管理しています。
2. 製造実績は / MESからSAPに連携されます。
3. 請求データは / SD側で作成され / FI側に転記されます。
4. 受注データを起点として / WMSに出荷指示を渡します。
5. マスタは / SAP側で管理されています。

## 4. 必背 10 句

1. SAPは / 基幹システムとしてデータを管理しています。
2. 周辺システムとは / インターフェースで連携しています。
3. 受注データを起点として / 出荷指示を渡します。
4. 製造実績は / MESからSAPに連携されます。
5. 在庫情報は / WMS側で管理されています。
6. 請求データは / FI側に会計伝票として転記されます。
7. データは / API経由で送信されます。
8. マスタ管理は / SAP側で行われています。
9. 連携頻度は / 日次またはリアルタイムです。
10. 詳細な項目定義は / インターフェース一覧で確認いたします。

## 5. 核心词汇

| 日语 | 读音 | 中文 | SAP 使用场景 | 错误提醒 |
|---|---|---|---|---|
| 基幹システム | きかんしすてむ | 核心系统 | ERP/SAP 在企业系统中的位置 | 不要简单说main system |
| 周辺システム | しゅうへんしすてむ | 周边系统 | MES/WMS/EC/报表系统 | 说明周边系统要说关系和数据 |
| インターフェース | いんたーふぇーす | 接口 | 系统间数据传输 | 不要只说連絡 |
| データ連携 | でーたれんけい | 数据联动 | 数据从一系统传到另一系统 | 需要说明方向和频率 |
| マスタ管理 | ますたかんり | 主数据管理 | 客户/供应商/品目/科目等主数据 | 要说明在哪边管理 |
| 起点 | きてん | 起点 | 业务流或数据流开始点 | 用〜を起点として |
| 経由 | けいゆ | 经由 | API/中间件/接口平台 | 用〜経由で送信されます |

## 6. 核心句型速查

### `〜と連携しています。`

- 中文：与某系统联动/连接。
- 适用：说明 SAP 与周边系统关系。
- SAP 例句：`SAPはMESと連携しています。`
- 中式错误：`SAPとMESは関係があります。`
- 更自然：`SAPはMESと連携しています。`

### `〜を起点として〜にデータを渡します。`

- 中文：以某数据为起点，把数据传给某系统。
- 适用：说明数据流方向。
- SAP 例句：`受注データを起点として、WMSに出荷指示を渡します。`
- 中式错误：`データが行きます。`
- 更自然：`受注データを起点として、WMSに出荷指示を渡します。`

### `〜経由で送信されます。`

- 中文：经由某接口/平台发送。
- 适用：说明接口路径或中间件。
- SAP 例句：`在庫データはAPI経由で送信されます。`
- 中式错误：`APIから送ります。`
- 更自然：`API経由で送信されます。`

### `〜側で管理されています。`

- 中文：由某侧管理。
- 适用：说明主数据或责任系统。
- SAP 例句：`品目マスタはSAP側で管理されています。`
- 中式错误：`SAPにあります。`
- 更自然：`SAP側で管理されています。`


## 7. 中式日语踩坑

| 中式表达 | 风险 | 更稳表达 |
|---|---|---|
| SAPとMESは関係があります。 | 关系太模糊 | SAPはMESと連携しています。 |
| データが行きます。 | 方向和对象不清 | 受注データを起点としてWMSに出荷指示を渡します。 |
| APIから送ります。 | 经由表达不自然 | API経由で送信されます。 |
| SAPにあります。 | 管理侧不清 | SAP側で管理されています。 |
| 全部SAPです。 | 过度简化架构 | SAPと周辺システムの役割を分けて説明します。 |

## 8. 课后作业

选择自己熟悉的模块，写一段“本模块与其他系统/模块的联动说明”。

### 作业骨架

```text
1. 位置づけ: ＿＿＿＿
2. 起点: ＿＿＿＿
3. 連携先: ＿＿＿＿
4. 管理側: ＿＿＿＿
5. 業務影響: ＿＿＿＿
```

## 9. 1 分钟录音作业

录 1 分钟系统架构说明，必须包含系统定位、数据起点、传输方向、管理侧、业务影响。

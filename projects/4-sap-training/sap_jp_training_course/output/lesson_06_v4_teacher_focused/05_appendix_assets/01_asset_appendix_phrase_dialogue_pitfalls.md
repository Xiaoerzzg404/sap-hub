## 2. 必背 10 句

1. SAPは / 基幹システムとしてデータを管理しています。
2. 周辺システムとは / インターフェースで連携しています。
3. 受注データを起点として / 出荷指示を渡します。
4. 製造実績は / MESからSAPに連携されます。
5. 在庫情報は / WMS側で管理されています。
6. 請求データは / FI側に会計伝票として転記されます。
7. データは / API経由で送信されます。
8. マスタ管理は / SAP側で行われています。
9. 連携頻度は / 日次またはリアルタイムです。

## 3. 对话 5 版本

### 3.1 标准版

```text
お客様：新しく参画したメンバーに、全体のシステム構成を説明していただけますか。
顧問：SAPは基幹システムとして受注から会計計上までのデータを管理しています。
顧問：製造実績はMESからSAPに連携され、/ 原価計算の基礎データとなります。
顧問：出荷指示は受注データを起点としてWMSに渡されます。
顧問：請求データはSD側で作成され、/ FI側に会計伝票として転記されます。
```

### 3.2 慢速领读版

```text
SAPは / 基幹システムとして / 受注から会計計上までのデータを管理しています。
製造実績は / MESからSAPに連携され、/ 原価計算の基礎データとなります。
出荷指示は / 受注データを起点として / WMSに渡されます。
請求データは / SD側で作成され、/ FI側に会計伝票として転記されます。
```

### 3.3 填空版

```text
SAPは ＿＿＿ 基幹システムとして ＿＿＿ 受注から会計計上までのデータを管理しています。
製造実績は ＿＿＿ MESからSAPに連携されます。
請求データは ＿＿＿ SD側で作成され ＿＿＿ FI側に転記されます。

```

### 3.4 中式错误版

```text
SAPとMESは関係があります。
データが行きます。
APIから送ります。
SAPにあります。
全部SAPです。
```

### 3.5 高级自然版

```text
SAPを基幹システムとして、受注、出荷、請求、会計計上までの主要データを管理しています。
製造実績はMESから連携され、原価計算や在庫評価の基礎データとして利用されます。
連携方式、頻度、管理側はインターフェース一覧で確認いたします。
```

## 4. 三档表达总表

| 功能 | 初级 | 标准 | 高级 |
|---|---|---|---|

| 以某数据为起点，把数据传给某系统。 | データが行きます。 | 受注データを起点として、WMSに出荷指示を渡します。 | SAPを基幹システムとして、受注、出荷、請求、会計計上までの主要データを管理しています。 |
| 经由某接口/平台发送。 | APIから送ります。 | API経由で送信されます。 | SAPを基幹システムとして、受注、出荷、請求、会計計上までの主要データを管理しています。 |
| 由某侧管理。 | SAPにあります。 | SAP側で管理されています。 | SAPを基幹システムとして、受注、出荷、請求、会計計上までの主要データを管理しています。 |

## 5. 中式日语踩坑 Top5

1. `SAPとMESは関係があります。` -> 关系太模糊 -> `SAPはMESと連携しています。`
2. `データが行きます。` -> 方向和对象不清 -> `受注データを起点としてWMSに出荷指示を渡します。`
3. `APIから送ります。` -> 经由表达不自然 -> `API経由で送信されます。`
4. `SAPにあります。` -> 管理侧不清 -> `SAP側で管理されています。`
5. `全部SAPです。` -> 过度简化架构 -> `SAPと周辺システムの役割を分けて説明します。`

## 7. 日语自然度复核

- 不要为了礼貌把句子拉得过长。
- 项目现场优先保证对象、动作、下一步清楚。
- 学生水平低时，先用标准版；高级顾问再练高级自然版。
- 如果表达涉及客户动作，注意尊敬/请求语气；涉及自己动作，注意自谦或丁宁。

## 3. 对话 5 版本

### 3.1 标准版

```text
お客様：本日からご参画とのことですね。簡単に自己紹介をお願いします。
顧問：本日よりFI担当として参画いたします、王と申します。
顧問：これまでFI領域を中心に要件確認とテスト支援を担当してまいりました。
顧問：本プロジェクトでは会計伝票とテスト支援を中心に対応いたします。
顧問：どうぞよろしくお願いいたします。
```

### 3.2 慢速领读版

```text
本日より / FI担当として参画いたします、王と申します。
これまで / FI領域を中心に / 要件確認とテスト支援を担当してまいりました。
本プロジェクトでは / 会計伝票とテスト支援を中心に / 対応いたします。

```

### 3.3 填空版

```text
本日より ＿＿＿ FI担当として参画いたします、王と申します。
どうぞよろしくお願いいたします。
お忙しいところ ＿＿＿ お時間をいただき、ありがとうございます。
本日の打合せ目的は ＿＿＿ 〇〇の認識合わせという理解でよろしいでしょうか。
```

### 3.4 中式错误版

```text
私は王です。
今日から入ります。
よろしくお願いしますね。
先に帰ります。
時間ありがとうございます。
```

### 3.5 高级自然版

```text
本日よりFI領域を担当いたします、王と申します。
要件確認とテスト支援を中心に、関係チームと連携しながら進めてまいります。
どうぞよろしくお願いいたします。
```

## 4. 三档表达总表

## 5. 中式日语踩坑 Top5

1. `私は王です。` -> 唐突，缺少申します和参画角色 -> `王と申します。本日よりFI担当として参画いたします。`
2. `今日から入ります。` -> 过于口语 -> `本日より参画いたします。`
3. `よろしくお願いしますね。` -> 语气过轻 -> `どうぞよろしくお願いいたします。`
4. `先に帰ります。` -> 像下班回家，不适合会议退场 -> `先に失礼いたします。`
5. `時間ありがとうございます。` -> 中式直译 -> `お時間をいただき、ありがとうございます。`

## 7. 日语自然度复核

- 不要为了礼貌把句子拉得过长。
- 项目现场优先保证对象、动作、下一步清楚。
- 学生水平低时，先用标准版；高级顾问再练高级自然版。
- 如果表达涉及客户动作，注意尊敬/请求语气；涉及自己动作，注意自谦或丁宁。

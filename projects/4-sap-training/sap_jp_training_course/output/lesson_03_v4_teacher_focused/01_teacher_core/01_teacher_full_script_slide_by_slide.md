## S-Slide 01：课程标题：日本职场基础礼仪

### 1. 本页目标

让学生知道 Lesson 03 不是普通日语课，而是围绕“第一次进入客户会议室/线上会议，需要自我介绍、确认会议目的、礼貌离开。”训练项目现场表达。

### 2. PPT 页面展示内容摘要

课程标题、主场景、训练产出：60 秒自我介绍。

### 3. 讲师口播稿：中文

大家好，今天进入 Lesson 03。题目是《日本职场基础礼仪》。听起来像普通职场课，但我们还是按 SAP 项目现场来训练。今天的主场景是：第一次进入客户会议室/线上会议，需要自我介绍、确认会议目的、礼貌离开。

本课结束时，大家不是只知道礼仪或表达规则，而是要能在真实项目里说出一段可用的话。我们会按“听真实场景 → 读硬指标 → 换模块对象 → 演会议场景 → 录 1 分钟作业”走，最后用录音作业检验能不能开口。

### 4. 讲师口播稿：日语示范

本日のテーマは / 日本职场基础礼仪です。
場面は / 初めてお客様の会議に参加し、自己紹介を行い、会議目的を確認し、最後に失礼する場面です。
今日のゴールは / SAPプロジェクトの現場で / すぐ使える表現にすることです。

- どうぞよろしくお願いいたします。

### 6. 学生练习 / 提问

### 7. 学生可能回答

- 担心语气太直接。
- 知道中文逻辑，但日语说不出来。
- 不知道怎样把 SAP 模块对象放进去。

## S-Slide 02：这节课解决什么 SAP 项目痛点

### 1. 本页目标

让学生看到本课与 SAP 项目交付直接相关。

### 2. PPT 页面展示内容摘要

第一次参画时，很多顾问会把自我介绍说成履历背诵，或者线上会议只说“你好”，没有说明角色、担当范围和协作方式。

### 3. 讲师口播稿：中文

第一次参画时，很多顾问会把自我介绍说成履历背诵，或者线上会议只说“你好”，没有说明角色、担当范围和协作方式。

如果表达过硬，客户可能觉得你不配合；如果表达过软，项目风险又说不清。所以我们训练的不是“更客气”，而是让礼貌服务于项目推进：该确认的确认，该说明的说明，该给下一步的给下一步。

### 4. 讲师口播稿：日语示范

この場面では / 丁寧さだけではなく、/ 役割、前提、次の対応を / 明確にすることが重要です。
どうぞよろしくお願いいたします。
SAPプロジェクトでは / 表現の自然さと / 作業の進め方を / 同時に伝える必要があります。

### 5. 讲师领读设计

- どうぞよろしくお願いいたします。
- 前提を / 確認いたします。
- 次の対応を / 明確にします。

### 6. 学生练习 / 提问

请学生说：这个场景里，如果表达不稳，会造成什么项目风险？

### 7. 学生可能回答

- 客户误解为已经承诺。
- 会议目的不清。
- 责任范围不清。
- 后续行动没有被记录。

### 8. 讲师点评与纠错话术

点评重点不是日语语法，而是项目风险：误解、过度承诺、边界不清、下一步不清。

### 9. 本页常见中式日语错误

错误：只追求句子礼貌，不说明项目动作。改法：每一句都要带出角色、对象、期限或下一步。

## S-Slide 07：为什么这个表达习惯很重要

### 1. 本页目标

解释文化与项目交付的关系。

### 2. PPT 页面展示内容摘要

日本项目中表达习惯服务于信任、确认和协作。

### 3. 讲师口播稿：中文

日本项目里，表达方式经常会影响推进速度。不是因为大家只看形式，而是因为会议参与方多、责任边界细、客户和顾问之间需要长期合作。表达太直接会让讨论停止；表达太模糊会让风险积累。

所以本课的文化点，要落到项目动作：进入会议 → 自我介绍 → 说明担当 → 确认目的 → 礼貌结束。只要你能按这个顺序说，礼貌就不再是表面功夫，而是推进项目的工具。

### 4. 讲师口播稿：日语示范

丁寧に話すことは / 目的ではありません。
誤解を減らし、/ 次の対応を明確にするために / 表現を整えます。
どうぞよろしくお願いいたします。

### 5. 讲师领读设计

- 誤解を減らします
- 次の対応を明確にします
- どうぞよろしくお願いいたします。

### 6. 学生练习 / 提问

问学生：礼貌表达和项目推进有什么关系？

### 7. 学生可能回答

- 客户更容易接受风险说明。
- 会议目的更清楚。
- 后续行动更容易确认。

### 8. 讲师点评与纠错话术

强调：礼貌不是软弱，而是让专业判断被听进去。

### 9. 本页常见中式日语错误

错误：把礼貌理解成不说风险。改法：用礼貌结构说清风险和下一步。

### 10. 过渡到下一页的话术

接下来把这个文化点落成 SAP 项目中的实际动作。

### 11. 本页必须背下来的日语

## S-Slide 08：在 SAP 项目中的实际含义

### 1. 本页目标

## S-Slide 09：五步表达结构

### 1. 本页目标

建立后续对话和作业的主骨架。

### 2. PPT 页面展示内容摘要

五步表达结构。

### 3. 讲师口播稿：中文

现在把主线固定成五步。每一步都不要太长，但不能缺。缺第一步，语气会突然；缺中间步骤，项目对象不清；缺最后一步，客户不知道下一步。

待会儿所有 Roleplay 和录音作业都按这五步来。你可以先用中文列点，再把日语句子填进去。

### 4. 讲师口播稿：日语示范

まず / 挨拶。
次に / 名乗り。
その後 / 担当説明。
最後に / 退室挨拶まで伝えます。

### 5. 讲师领读设计

- まず / 挨拶
- 次に / 名乗り
- 最後に / 退室挨拶

### 6. 学生练习 / 提问

请学生用中文做 30 秒结构练习。

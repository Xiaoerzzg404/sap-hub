## 1. 热身：硬指标跟读

请学生逐句跟读，第二遍加入 `/` 停顿。

- 現在のステータスは / マスタ移行が一部遅延している状況です。
- 本番移行作業は / 本日22時までに完了予定です。
- 問題が発生した場合は / 切り戻し手順に基づいて対応します。
- ハイパーケア期間中は / 優先度の高い問い合わせから順次対応します。
- 次回は / 30分後に更新状況をご報告いたします。

## 2. 填空练习

- 句型：`〜までに完了予定です。`
  - 填空：______ / 本日22時までに / 完了予定です。
  - 替换任务：汇报主数据导入完成时间。
- 句型：`〜が発生した場合、〜で対応します。`
  - 填空：______ / 問題が発生した場合は / 切り戻し手順に基づいて対応します。
  - 替换任务：说明接口失败时的处理。
- 句型：`現在のステータスは〜です。`
  - 填空：______ / 現在のステータスは / マスタ移行が一部遅延している状況です。
  - 替换任务：汇报测试用户创建进度。
- 句型：`振り返りとして、〜を改善します。`
  - 填空：______ / 振り返りとして / 事前チェックリストの確認手順を改善します。
  - 替换任务：说明上线后改善点。

## 3. 改错练习

- 错误：22時に終わると思います。
- 改法：本日22時までに / 完了予定です。

- 错误：何かあったら戻します。
- 改法：問題が発生した場合は / 切り戻し手順に基づいて対応します。

- 错误：今ちょっと遅いです。
- 改法：現在のステータスは / マスタ移行が一部遅延している状況です。

- 错误：次は気をつけます。
- 改法：振り返りとして / 事前チェックリストの確認手順を改善します。

## 4. 课堂互动

30秒状态汇报演练：每人用日语汇报一个上线问题的Status。

## 5. Roleplay

| 角色 | 任务 | 必须说出的内容 |
|---|---|---|
| PM / 主持人 | 控制会议方向 | 本页目的、确认事项、下一步 |
| 模块顾问 | 说明自己负责范围 | 模块、对象、风险、确认路径 |
| 客户侧用户 | 提出追问 | 资料、期限、责任人 |
| PMO / 协作团队 | 补充路径 | 课题管理、升级路线、记录方式 |

## 6. 小测

1. 听一句，写出责任主体。
2. 读一句，加入停顿。
3. 换一句，换成自己的模块。
4. 改一句，把中式表达改自然。
5. 说一句，补上下一步。

## 1. 本课主场景

上线当天主数据导入延迟，PM要求每30分钟汇报状态。顾问需要汇报进度、风险、对策、下一次更新时间。

## 2. 硬指标 5 句

1. 現在のステータスは / マスタ移行が一部遅延している状況です。
2. 本番移行作業は / 本日22時までに完了予定です。
3. 問題が発生した場合は / 切り戻し手順に基づいて対応します。
4. ハイパーケア期間中は / 優先度の高い問い合わせから順次対応します。
5. 次回は / 30分後に更新状況をご報告いたします。

## 3. 核心句型速查

### 〜までに完了予定です。
- 中文：预计在某时间前完成。
- 场景：上线任务状态汇报。
- SAP 例句：本番移行作業は / 本日22時までに完了予定です。
- 中式错误：22時に終わると思います。
- 更自然：本日22時までに / 完了予定です。

### 〜が発生した場合、〜で対応します。
- 中文：如果发生某问题，用某方式处理。
- 场景：上线风险和应急预案。
- SAP 例句：問題が発生した場合は / 切り戻し手順に基づいて対応します。
- 中式错误：何かあったら戻します。
- 更自然：問題が発生した場合は / 切り戻し手順に基づいて対応します。

### 現在のステータスは〜です。
- 中文：当前状态是某情况。
- 场景：定时状态汇报。
- SAP 例句：現在のステータスは / マスタ移行が一部遅延している状況です。
- 中式错误：今ちょっと遅いです。
- 更自然：現在のステータスは / マスタ移行が一部遅延している状況です。

### 振り返りとして、〜を改善します。
- 中文：作为复盘，将改善某事项。
- 场景：上线后复盘和再发防止。
- SAP 例句：振り返りとして / チェックリストの確認手順を改善します。
- 中式错误：次は気をつけます。
- 更自然：振り返りとして / 事前チェックリストの確認手順を改善します。

## 5. 课后作业

- 主作业：写一份上线前检查清单和上线问题日报模板。
- 录音作业：录 1 分钟，必须包含本课五步结构。
- 五步结构：現在ステータスを言う → 完了予定を言う → リスクを言う → 対応策を言う → 次回更新時刻を言う
- 提交前自查：是否说清对象、动作、确认路径、下一步。

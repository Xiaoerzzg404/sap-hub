## 1. 热身：硬指标跟读

请学生逐句跟读，第二遍加入 `/` 停顿。

- まず / 発生日時、対象伝票番号、エラーメッセージをご共有ください。
- 状況を確認いたします。
- 原因は / マスタ設定の不整合と考えられます。
- 暫定対応として / 手動で再処理をお願いいたします。
- 恒久対応として / マスタ登録時のチェックを追加する案を検討します。

## 2. 填空练习

- 句型：`状況を確認いたします。`
  - 填空：______ / まず / 状況を確認いたします。
  - 替换任务：受理用户报错。
- 句型：`原因は〜と考えられます。`
  - 填空：______ / 現時点では / 原因は〜と考えられます。
  - 替换任务：说明可能是权限问题。
- 句型：`暫定対応として〜をお願いいたします。`
  - 填空：______ / 暫定対応として / 手動で再処理をお願いいたします。
  - 替换任务：请求暂时使用手工补录。
- 句型：`恒久対応については〜を検討します。`
  - 填空：______ / 恒久対応については / チェック追加の案を検討します。
  - 替换任务：说明后续增加检查逻辑。

## 3. 改错练习

- 错误：ちょっと見ます。
- 改法：まず / 状況を確認いたします。

- 错误：原因はこれです。
- 改法：現時点では / 原因は〜と考えられます。

- 错误：とりあえず手でやってください。
- 改法：暫定対応として / 手動で再処理をお願いいたします。

- 错误：あとでちゃんと直します。
- 改法：恒久対応については / チェック追加の案を検討します。

## 4. 课堂互动

故障初问八项：いつ、誰が、どこで、何を、どの画面で、どんなエラー、影響、緊急度。

## 5. Roleplay

| 角色 | 任务 | 必须说出的内容 |
|---|---|---|
| PM / 主持人 | 控制会议方向 | 本页目的、确认事项、下一步 |
| 模块顾问 | 说明自己负责范围 | 模块、对象、风险、确认路径 |
| 客户侧用户 | 提出追问 | 资料、期限、责任人 |
| PMO / 协作团队 | 补充路径 | 课题管理、升级路线、记录方式 |

## 6. 小测

1. 听一句，写出责任主体。
2. 读一句，加入停顿。
3. 换一句，换成自己的模块。
4. 改一句，把中式表达改自然。
5. 说一句，补上下一步。

## 1. 热身：硬指标跟读

请学生逐句跟读，第二遍加入 `/` 停顿。

- 本件は / アプリチーム側で一次調査します。
- 必要に応じて / Basisチームへエスカレーションします。
- お客様側の承認後 / 開発チームへ依頼します。
- 連絡ルートを明確にするため / 課題管理表経由でご連絡ください。
- FI領域は / 弊社側で担当しております。

## 2. 填空练习

- 句型：`〜側で対応します。`
  - 填空：______ / 本件は / 弊社側で一次対応いたします。
  - 替换任务：把“客户方先确认主数据”改成日语。
- 句型：`〜経由で連絡します。`
  - 填空：______ / 情報の抜け漏れを防ぐため / 課題管理表経由でご連絡いただけますでしょうか。
  - 替换任务：把“请通过 PMO 联系开发团队”改成日语。
- 句型：`〜を担当しております。`
  - 填空：______ / FI領域の要件整理を担当しております。
  - 替换任务：用自己的模块说一句职责介绍。
- 句型：`〜にエスカレーションします。`
  - 填空：______ / 影響範囲が大きい場合は / PMOにエスカレーションいたします。
  - 替换任务：把“权限问题升级给安全团队”改成日语。

## 3. 改错练习

- 错误：私たちはこれをやります。
- 改法：本件は / 弊社側で一次対応いたします。

- 错误：メールで直接全部送ってください。
- 改法：情報の抜け漏れを防ぐため / 課題管理表経由でご連絡いただけますでしょうか。

- 错误：私はFIをします。
- 改法：FI領域の要件整理を担当しております。

- 错误：上に言います。
- 改法：影響範囲が大きい場合は / PMOにエスカレーションいたします。

## 4. 课堂互动

用一张项目组织图练习：学生介绍每个角色的职责和沟通路径。

## 5. Roleplay

| 角色 | 任务 | 必须说出的内容 |
|---|---|---|
| PM / 主持人 | 控制会议方向 | 本页目的、确认事项、下一步 |
| 模块顾问 | 说明自己负责范围 | 模块、对象、风险、确认路径 |
| 客户侧用户 | 提出追问 | 资料、期限、责任人 |
| PMO / 协作团队 | 补充路径 | 课题管理、升级路线、记录方式 |

## 6. 小测

1. 听一句，写出责任主体。
2. 读一句，加入停顿。
3. 换一句，换成自己的模块。
4. 改一句，把中式表达改自然。
5. 说一句，补上下一步。

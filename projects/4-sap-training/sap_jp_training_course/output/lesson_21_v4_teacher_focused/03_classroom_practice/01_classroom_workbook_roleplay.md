## 1. 热身：硬指标跟读

请学生逐句跟读，第二遍加入 `/` 停顿。

- 体調不良のため / 本日は午前休を申請させていただきます。
- 会議資料を / 共有フォルダに格納いたしました。
- 恐れ入りますが / 検証用ユーザーの申請方法を教えていただけますでしょうか。
- 本日は / 在宅勤務とさせていただきます。
- お手数ですが / 資料の確認をお願いできますでしょうか。

## 2. 填空练习

- 句型：`〜させていただきます。`
  - 填空：______ / 体調不良のため / 本日は午前休を申請させていただきます。
  - 替换任务：说明今天下午早退。
- 句型：`〜を申請いたします。`
  - 填空：______ / 休暇を申請いたします。
  - 替换任务：申请验证用用户。
- 句型：`〜をお願いできますでしょうか。`
  - 填空：______ / お手数ですが / 資料の確認をお願いできますでしょうか。
  - 替换任务：请同事代为确认会议资料。
- 句型：`本日は在宅勤務とさせていただきます。`
  - 填空：______ / 本日は / 在宅勤務とさせていただきます。
  - 替换任务：说明上午在宅下午出社。

## 3. 改错练习

- 错误：私は休みます。
- 改法：体調不良のため / 本日は午前休を申請させていただきます。

- 错误：休みを出します。
- 改法：休暇を申請いたします。

- 错误：資料を見てください。
- 改法：お手数ですが / 資料の確認をお願いできますでしょうか。

- 错误：今日は家で仕事します。
- 改法：本日は / 在宅勤務とさせていただきます。

## 4. 课堂互动

日常口语卡片抽签：休假、迟到、在家办公、资料共享、请同事帮忙，各说一段。

## 5. Roleplay

| 角色 | 任务 | 必须说出的内容 |
|---|---|---|
| PM / 主持人 | 控制会议方向 | 本页目的、确认事项、下一步 |
| 模块顾问 | 说明自己负责范围 | 模块、对象、风险、确认路径 |
| 客户侧用户 | 提出追问 | 资料、期限、责任人 |
| PMO / 协作团队 | 补充路径 | 课题管理、升级路线、记录方式 |

## 6. 小测

1. 听一句，写出责任主体。
2. 读一句，加入停顿。
3. 换一句，换成自己的模块。
4. 改一句，把中式表达改自然。
5. 说一句，补上下一步。

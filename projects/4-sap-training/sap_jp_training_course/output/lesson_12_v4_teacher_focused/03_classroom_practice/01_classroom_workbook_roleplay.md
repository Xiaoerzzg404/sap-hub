## 1. 热身：硬指标跟读

请学生逐句跟读，第二遍加入 `/` 停顿。

- FI/CO領域を中心に / 月次決算と原価計算を担当した経験があります。
- 財務会計に / 強みがあります。
- MMとの連携が / 多いです。
- SDでは / 受注、出荷、請求、会計転記までの流れを理解する必要があります。
- 今後は / クロスモジュールの理解を強化したいと考えています。

## 2. 填空练习

- 句型：`〜を担当した経験があります。`
  - 填空：______ / FI領域で / 月次決算対応を担当した経験があります。
  - 替换任务：用自己的模块说一句经验。
- 句型：`〜に強みがあります。`
  - 填空：______ / FI領域の要件整理とテスト支援に強みがあります。
  - 替换任务：把“我擅长测试”说得更项目化。
- 句型：`〜との連携が多いです。`
  - 填空：______ / MM領域との連携が多く / 特に入庫から買掛計上までを確認します。
  - 替换任务：说出你的模块和另一个模块的联动。
- 句型：`〜の知識も必要になります。`
  - 填空：______ / SD領域では / 販売プロセスと会計連携の知識も必要になります。
  - 替换任务：把“还要懂业务流程”改成自然日语。

## 3. 改错练习

- 错误：私はFIをやったことがあります。
- 改法：FI領域で / 月次決算対応を担当した経験があります。

- 错误：私はFIが強いです。
- 改法：FI領域の要件整理とテスト支援に強みがあります。

- 错误：MMと関係があります。
- 改法：MM領域との連携が多く / 特に入庫から買掛計上までを確認します。

- 错误：SDも知る必要です。
- 改法：SD領域では / 販売プロセスと会計連携の知識も必要になります。

## 4. 课堂互动

模块一分钟：每位学生选择一个模块，用3句话说明模块职责、相关模块、常见课题。

## 5. Roleplay

| 角色 | 任务 | 必须说出的内容 |
|---|---|---|
| PM / 主持人 | 控制会议方向 | 本页目的、确认事项、下一步 |
| 模块顾问 | 说明自己负责范围 | 模块、对象、风险、确认路径 |
| 客户侧用户 | 提出追问 | 资料、期限、责任人 |
| PMO / 协作团队 | 补充路径 | 课题管理、升级路线、记录方式 |

## 6. 小测

1. 听一句，写出责任主体。
2. 读一句，加入停顿。
3. 换一句，换成自己的模块。
4. 改一句，把中式表达改自然。
5. 说一句，补上下一步。

## 1. 本课硬指标 5 句详解

## 2. 必背 10 句

1. 本番環境へのアクセスには / 申請が必要です。
2. 調査には / 参照権限が必要です。
3. 本番環境の直接変更は / 監査上認められていません。
4. 個人情報を含むデータを / ローカルPCに保存してはいけません。
5. 機密情報を / 外部に持ち出さないようお願いいたします。
6. 必要な権限は / 申請フローに基づいて付与されます。
7. アクセスログを / 取得する必要があります。

## 3. 对话 5 版本

### 3.1 标准版

```text
お客様：原因調査のため、本番データをダウンロードして確認できますか。
顧問：調査には参照権限が必要です。
顧問：ただし本番データをローカルPCに保存してはいけません。
顧問：監査上アクセスログの取得と監査証跡の保存が求められます。
顧問：可能であればマスキングデータまたは管理された環境で分析いたします。
```

## 5. 中式日语踩坑 Top5

1. `データを落として見ます。` -> 违规风险极高 -> `管理された環境で分析いたします。`
2. `権限をください。` -> 请求太粗且无理由 -> `調査には参照権限が必要です。`
3. `本番で直します。` -> 生产直接变更风险 -> `本番環境の直接変更は監査上認められていません。`
4. `PCに保存します。` -> 本地保存风险 -> `ローカルPCに保存しないようお願いいたします。`
5. `ログはいりません。` -> 审计证迹缺失 -> `監査上、アクセスログの取得が求められます。`

## 7. 日语自然度复核

- 不要为了显得专业而说无来源断言。
- 趋势、市场、制度类表达优先用 `傾向があります`、`確認が必要です`、`ケースがあります`。
- 项目现场优先保证对象、动作、下一步清楚。

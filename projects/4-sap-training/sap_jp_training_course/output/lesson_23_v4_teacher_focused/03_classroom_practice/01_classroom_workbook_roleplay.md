## 1. 热身：硬指标跟读

请学生逐句跟读，第二遍加入 `/` 停顿。

- 会計締めへの影響があるため / FI側としては本日中の確認が必要です。
- 業務部門とIT部門の認識を合わせる場を / 設定させてください。
- 優先度を確認したうえで / 対応順を決めたいと考えております。
- SD側と / 請求データの条件を調整させてください。
- 明日午前中までに / ご対応いただくことは可能でしょうか。

## 2. 填空练习

- 句型：`〜と調整させてください。`
  - 填空：______ / SD側と / 条件を調整させてください。
  - 替换任务：请求和采购部门协调。
- 句型：`〜の観点では、〜が必要です。`
  - 填空：______ / 会計締めの観点では / 本日中の確認が必要です。
  - 替换任务：从库存视角说明必要性。
- 句型：`優先度を確認させてください。`
  - 填空：______ / 対応順を決めるため / 優先度を確認させてください。
  - 替换任务：确认三个缺陷的优先级。
- 句型：`〜までにご対応いただくことは可能でしょうか。`
  - 填空：______ / 明日午前中までに / ご対応いただくことは可能でしょうか。
  - 替换任务：请求今天下班前确认。

## 3. 改错练习

- 错误：SDと話します。
- 改法：SD側と / 条件を調整させてください。

- 错误：FIは今日必要です。
- 改法：会計締めの観点では / 本日中の確認が必要です。

- 错误：どれが大事ですか。
- 改法：対応順を決めるため / 優先度を確認させてください。

- 错误：明日までにやってください。
- 改法：明日午前中までに / ご対応いただくことは可能でしょうか。

## 4. 课堂互动

三方协调Roleplay：FI顾问、SD顾问、业务用户，围绕“请款/发票/会计凭证差异”达成下一步。

## 5. Roleplay

| 角色 | 任务 | 必须说出的内容 |
|---|---|---|
| PM / 主持人 | 控制会议方向 | 本页目的、确认事项、下一步 |
| 模块顾问 | 说明自己负责范围 | 模块、对象、风险、确认路径 |
| 客户侧用户 | 提出追问 | 资料、期限、责任人 |
| PMO / 协作团队 | 补充路径 | 课题管理、升级路线、记录方式 |

## 6. 小测

1. 听一句，写出责任主体。
2. 读一句，加入停顿。
3. 换一句，换成自己的模块。
4. 改一句，把中式表达改自然。
5. 说一句，补上下一步。

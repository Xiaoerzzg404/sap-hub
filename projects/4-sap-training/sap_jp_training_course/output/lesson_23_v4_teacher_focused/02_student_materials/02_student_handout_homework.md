## 1. 本课主场景

FI和SD对同一个发票问题看法不同，PM要求今天定方向。顾问需要组织协调并争取关键人员参加。

## 2. 硬指标 5 句

1. 会計締めへの影響があるため / FI側としては本日中の確認が必要です。
2. 業務部門とIT部門の認識を合わせる場を / 設定させてください。
3. 優先度を確認したうえで / 対応順を決めたいと考えております。
4. SD側と / 請求データの条件を調整させてください。
5. 明日午前中までに / ご対応いただくことは可能でしょうか。

## 3. 核心句型速查

### 〜と調整させてください。
- 中文：请允许我和某方协调。
- 场景：跨模块/跨部门协调。
- SAP 例句：SD側と / 請求データの条件を調整させてください。
- 中式错误：SDと話します。
- 更自然：SD側と / 条件を調整させてください。

### 〜の観点では、〜が必要です。
- 中文：从某视角看，需要某事项。
- 场景：说明本部门立场，不攻击对方。
- SAP 例句：会計締めの観点では / 本日中の確認が必要です。
- 中式错误：FIは今日必要です。
- 更自然：会計締めの観点では / 本日中の確認が必要です。

### 優先度を確認させてください。
- 中文：请允许确认优先级。
- 场景：资源冲突/多问题排序。
- SAP 例句：対応順を決めるため / 優先度を確認させてください。
- 中式错误：どれが大事ですか。
- 更自然：対応順を決めるため / 優先度を確認させてください。

### 〜までにご対応いただくことは可能でしょうか。
- 中文：能否在某期限前处理。
- 场景：争取资源和期限。
- SAP 例句：明日午前中までに / ご対応いただくことは可能でしょうか。
- 中式错误：明日までにやってください。
- 更自然：明日午前中までに / ご対応いただくことは可能でしょうか。

## 5. 课后作业

- 主作业：写一段跨部门协调发言，必须包含背景、影响、请求、期限、下一步。
- 录音作业：录 1 分钟，必须包含本课五步结构。
- 五步结构：背景を共有する → 影響を説明する → 関係部署と調整する → 優先度を確認する → 次の対応を合意する
- 提交前自查：是否说清对象、动作、确认路径、下一步。

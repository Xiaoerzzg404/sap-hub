## 1. 本课主场景

Panaya/Jira/Excel中发现测试失败，需要向客户和开发说明问题，并保留Evidence。

## 2. 硬指标 5 句

1. テストケースの目的は / 請求書登録後に会計伝票が正しく転記されることです。
2. 期待結果は消費税が自動計算されることですが / 実際には税額がゼロになりました。
3. 再現手順は / 以下の通りです。
4. 修正内容を確認後 / 同じデータ条件で再テストを実施します。
5. 証跡として / 画面キャプチャを添付いたします。

## 3. 核心句型速查

### テストケースの目的は〜です。
- 中文：说明测试用例目的。
- 场景：测试说明、用例评审。
- SAP 例句：このテストケースの目的は / 請求書登録後に会計伝票が正しく転記されることです。
- 中式错误：このテストはこれを見ます。
- 更自然：テストケースの目的は / 会計伝票が正しく転記されることを確認することです。

### 期待結果は〜ですが、実際には〜となりました。
- 中文：对比预期与实际。
- 场景：缺陷报告核心表达。
- SAP 例句：期待結果は消費税が自動計算されることですが / 実際には税額がゼロになりました。
- 中式错误：期待と違います。
- 更自然：期待結果は〜ですが / 実際には〜となりました。

### 再現手順は以下の通りです。
- 中文：说明复现步骤如下。
- 场景：给开发/Basis/客户复现缺陷。
- SAP 例句：再現手順は / 以下の通りです。
- 中式错误：もう一回やり方はこれです。
- 更自然：再現手順は / 以下の通りです。

### 修正後、再テストを実施します。
- 中文：修正后执行再测试。
- 场景：缺陷关闭前确认。
- SAP 例句：修正内容を確認後 / 同じデータ条件で再テストを実施します。
- 中式错误：直したらまたテストします。
- 更自然：修正後 / 同じデータ条件で再テストを実施します。

## 4. 高频词汇

| 日语 | 读音 | 中文 | SAP 使用场景 | 错误提醒 |
|---|---|---|---|---|
| テストケース | テストケース | 测试用例 | 测试执行、评审 | 要有目的和期待结果。 |
| 前提条件 | ぜんていじょうけん | 前提条件 | 数据、用户、环境 | 缺少前提会无法复现。 |
| 期待結果 | きたいけっか | 预期结果 | 缺陷判断 | 要和实际结果对比。 |
| 実績結果 | じっせきけっか | 实际结果 | 测试记录 | 不要只写NG。 |
| 再テスト | さいテスト | 再测试 | 修正后确认 | 使用相同条件更清楚。 |
| 証跡 | しょうせき | 证据 | 截图、日志、凭证号 | 必须可追溯。 |
| 優先度 | ゆうせんど | 优先级 | 缺陷处理顺序 | 与影响范围一起判断。 |
| 再現手順 | さいげんてじゅん | 复现步骤 | 开发调查 | 要按步骤编号。 |

## 5. 课后作业

- 主作业：根据自己模块写一个测试用例和一个缺陷报告，日语完成。
- 录音作业：录 1 分钟，必须包含本课五步结构。
- 五步结构：目的を言う → 前提条件を言う → 期待結果と実績結果を比べる → 再現手順を示す → 再テストを言う
- 提交前自查：是否说清对象、动作、确认路径、下一步。

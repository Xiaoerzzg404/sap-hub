## 1. 热身：硬指标跟读

请学生逐句跟读，第二遍加入 `/` 停顿。

- テストケースの目的は / 請求書登録後に会計伝票が正しく転記されることです。
- 期待結果は消費税が自動計算されることですが / 実際には税額がゼロになりました。
- 再現手順は / 以下の通りです。
- 修正内容を確認後 / 同じデータ条件で再テストを実施します。
- 証跡として / 画面キャプチャを添付いたします。

## 2. 填空练习

- 句型：`テストケースの目的は〜です。`
  - 填空：______ / テストケースの目的は / 会計伝票が正しく転記されることを確認することです。
  - 替换任务：说明付款测试目的。
- 句型：`期待結果は〜ですが、実際には〜となりました。`
  - 填空：______ / 期待結果は〜ですが / 実際には〜となりました。
  - 替换任务：说明金额差异。
- 句型：`再現手順は以下の通りです。`
  - 填空：______ / 再現手順は / 以下の通りです。
  - 替换任务：写三步复现步骤。
- 句型：`修正後、再テストを実施します。`
  - 填空：______ / 修正後 / 同じデータ条件で再テストを実施します。
  - 替换任务：说明修正后测试计划。

## 3. 改错练习

- 错误：このテストはこれを見ます。
- 改法：テストケースの目的は / 会計伝票が正しく転記されることを確認することです。

- 错误：期待と違います。
- 改法：期待結果は〜ですが / 実際には〜となりました。

- 错误：もう一回やり方はこれです。
- 改法：再現手順は / 以下の通りです。

- 错误：直したらまたテストします。
- 改法：修正後 / 同じデータ条件で再テストを実施します。

## 4. 课堂互动

缺陷报告模板填空：現象、再現手順、期待結果、実際結果、影響、添付証跡。

## 5. Roleplay

| 角色 | 任务 | 必须说出的内容 |
|---|---|---|
| PM / 主持人 | 控制会议方向 | 本页目的、确认事项、下一步 |
| 模块顾问 | 说明自己负责范围 | 模块、对象、风险、确认路径 |
| 客户侧用户 | 提出追问 | 资料、期限、责任人 |
| PMO / 协作团队 | 补充路径 | 课题管理、升级路线、记录方式 |

## 6. 小测

1. 听一句，写出责任主体。
2. 读一句，加入停顿。
3. 换一句，换成自己的模块。
4. 改一句，把中式表达改自然。
5. 说一句，补上下一步。

# 日本 SAP 项目会议前速查表：客户坚持现行流程时

updated_by: codex
updated_at: 2026-05-16T23:02:00+09:00

## 1. 会议前确认清单

| 检查项 | 你需要准备什么 |
|---|---|
| 业务对象 | 公司代码、销售组织、采购组织、工厂、权限角色、接口、API 等。 |
| 现行流程 | 客户现在怎么做，是否有例外运用，谁批准，何时发生。 |
| SAP 标准差异 | 标准流程是否需要审批、入库、出荷、请求、会计转记等控制点。 |
| 影响范围 | FI、CO、SD、MM、PP、Basis、ABAP / BTP 是否受影响。 |
| 不能现场承诺的点 | 标准功能可否满足、是否需要扩张/增强、测试范围是否扩大。 |

## 2. 不要直接说的表达

- それは違います。
- 無理です。
- できません。
- あなたの意味は何ですか。
- 資料をください。
- 危ないです。

## 3. 推荐使用的三步表达

1. ご意向は理解いたしました。
2. ただ、一点確認させてください。〇〇という理解でよろしいでしょうか。
3. △△の観点では、影響範囲を確認する必要があると考えております。一度、前提条件を整理したうえで、次回ご説明いたします。

## 4. 需要确认的项目要素

| 要素 | 日语确认句 |
|---|---|
| 范围 | 対象範囲は〇〇までという理解でよろしいでしょうか。 |
| 组织单位 | 全ての〇〇で同じ運用が必要でしょうか。 |
| 例外条件 | この例外運用はどのケースで発生しますでしょうか。 |
| 频率 | 月末のみでしょうか。それとも通常運用として発生しますでしょうか。 |
| 影响模块 | 関連モジュールへの影響も含めて確認させてください。 |
| 后续动作 | 一度整理したうえで、次回の定例会でご説明いたします。 |

## 5. 不同模块的确认问题

| 模块 | 可以确认的问题 | 日语表达 |
|---|---|---|
| FI / CO | 是否所有公司代码都适用，是否影响会计连携、内部统制、成本对象。 | 全ての会社コードで同じ運用が必要という理解でよろしいでしょうか。会計連携と内部統制への影響も確認させてください。 |
| SD | 是否所有销售组织都适用，是否影响出荷、请求、売掛连携。 | 全ての販売組織に適用されるという理解でよろしいでしょうか。出荷、請求、売掛連携への影響を確認いたします。 |
| MM | 是否只针对总部采购，是否影响入库、请款照合、库存评价。 | 本社購買のみ対象という理解でよろしいでしょうか。入庫、請求書照合、在庫評価への影響を確認いたします。 |
| PP | 是否所有工厂都适用，是否影响生产指図、実績、原価。 | 全てのプラントで同じ運用が必要でしょうか。生産指図、実績計上、原価への影響を確認いたします。 |
| Basis | 是否临时权限，是否影响本番环境、移送、ジョブ。 | 一時的な権限付与という理解でよろしいでしょうか。本番環境、移送、ジョブ運用への影響も確認いたします。 |
| ABAP / BTP | 是否需要增强、API 连携、Fiori 画面调整。 | 標準機能で対応できる範囲と、アドオンやAPI連携が必要になる範囲を整理させてください。 |

## 6. 带回确认表达

- 一度持ち帰って確認いたします。
- 関連モジュールへの影響も含めて確認いたします。
- 標準機能でどこまで対応できるか確認いたします。
- 確認結果は次回の定例会でご説明いたします。

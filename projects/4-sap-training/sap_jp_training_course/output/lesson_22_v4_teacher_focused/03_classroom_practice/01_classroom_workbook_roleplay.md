## 1. 热身：硬指标跟读

请学生逐句跟读，第二遍加入 `/` 停顿。

- FI設定内容の確認につきまして / 以下の通りご連絡いたします。
- ご確認のほど / よろしくお願いいたします。
- 本日の議事内容とアクションアイテムを / 以下に記載いたします。
- 認識相違がございましたら / 本日中にご連絡いただけますと幸いです。
- アクションアイテムとして / 現行業務フローのご共有をお願いいたします。

## 2. 填空练习

- 句型：`〜につきまして、以下の通りご連絡いたします。`
  - 填空：______ / FI設定内容の確認につきまして / 以下の通りご連絡いたします。
  - 替换任务：写会议纪要邮件开头。
- 句型：`ご確認のほど、よろしくお願いいたします。`
  - 填空：______ / ご確認のほど / よろしくお願いいたします。
  - 替换任务：请客户确认附件。
- 句型：`議事内容は以下の通りです。`
  - 填空：______ / 議事内容は / 以下の通りです。
  - 替换任务：引出三条会议内容。
- 句型：`アクションアイテムとして〜をお願いいたします。`
  - 填空：______ / アクションアイテムとして / 〜をお願いいたします。
  - 替换任务：要求下次前提供科目表。

## 3. 改错练习

- 错误：FI設定について連絡します。
- 改法：FI設定内容の確認につきまして / 以下の通りご連絡いたします。

- 错误：確認してください。
- 改法：ご確認のほど / よろしくお願いいたします。

- 错误：今日話したことはこれです。
- 改法：議事内容は / 以下の通りです。

- 错误：宿題としてやってください。
- 改法：アクションアイテムとして / 〜をお願いいたします。

## 4. 课堂互动

老师展示一份糟糕纪要，学生找出缺少的要素并改写。

## 5. Roleplay

| 角色 | 任务 | 必须说出的内容 |
|---|---|---|
| PM / 主持人 | 控制会议方向 | 本页目的、确认事项、下一步 |
| 模块顾问 | 说明自己负责范围 | 模块、对象、风险、确认路径 |
| 客户侧用户 | 提出追问 | 资料、期限、责任人 |
| PMO / 协作团队 | 补充路径 | 课题管理、升级路线、记录方式 |

## 6. 小测

1. 听一句，写出责任主体。
2. 读一句，加入停顿。
3. 换一句，换成自己的模块。
4. 改一句，把中式表达改自然。
5. 说一句，补上下一步。

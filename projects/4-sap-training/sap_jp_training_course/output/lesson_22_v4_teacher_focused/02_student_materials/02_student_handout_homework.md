## 1. 本课主场景

需求会议结束后，顾问需要发送会议纪要，明确决定事项、未决事项、行动项、期限、负责人。

## 2. 硬指标 5 句

1. FI設定内容の確認につきまして / 以下の通りご連絡いたします。
2. ご確認のほど / よろしくお願いいたします。
3. 本日の議事内容とアクションアイテムを / 以下に記載いたします。
4. 認識相違がございましたら / 本日中にご連絡いただけますと幸いです。
5. アクションアイテムとして / 現行業務フローのご共有をお願いいたします。

## 3. 核心句型速查

### 〜につきまして、以下の通りご連絡いたします。
- 中文：关于某事项，按如下内容联系。
- 场景：邮件正文开头。
- SAP 例句：FI設定内容の確認につきまして / 以下の通りご連絡いたします。
- 中式错误：FI設定について連絡します。
- 更自然：FI設定内容の確認につきまして / 以下の通りご連絡いたします。

### ご確認のほど、よろしくお願いいたします。
- 中文：烦请确认。
- 场景：邮件结尾/请求确认。
- SAP 例句：ご確認のほど / よろしくお願いいたします。
- 中式错误：確認してください。
- 更自然：ご確認のほど / よろしくお願いいたします。

### 議事内容は以下の通りです。
- 中文：会议内容如下。
- 场景：会议纪要正文。
- SAP 例句：本日の議事内容は / 以下の通りです。
- 中式错误：今日話したことはこれです。
- 更自然：議事内容は / 以下の通りです。

### アクションアイテムとして〜をお願いいたします。
- 中文：作为行动项，请做某事。
- 场景：明确待办、责任和期限。
- SAP 例句：アクションアイテムとして / 現行業務フローのご共有をお願いいたします。
- 中式错误：宿題としてやってください。
- 更自然：アクションアイテムとして / 〜をお願いいたします。

## 4. 高频词汇

| 日语 | 读音 | 中文 | SAP 使用场景 | 错误提醒 |
|---|---|---|---|---|
| 件名 | けんめい | 邮件标题 | 邮件标题 | 要能一眼看懂目的。 |
| 議事録 | ぎじろく | 会议纪要 | 会议后确认 | 不是逐字记录，而是决定和行动。 |
| アジェンダ | アジェンダ | 议程 | 会议通知 | 提前共有。 |
| 宿題事項 | しゅくだいじこう | 待办事项 | 行动项 | 商务场景可用但要明确担当。 |
| 期限 | きげん | 期限 | 行动项管理 | 必须具体日期。 |
| 決定事項 | けっていじこう | 决定事项 | 纪要核心 | 不要和讨论事项混在一起。 |
| 未決事項 | みけつじこう | 未决事项 | 后续确认 | 要写下一步。 |
| 認識相違 | にんしきそうい | 认知差异 | 纪要确认 | 日本项目非常常用。 |

## 5. 课后作业

- 主作业：根据课堂会议内容写一封会议纪要邮件。
- 录音作业：录 1 分钟，必须包含本课五步结构。
- 五步结构：件名を書く → 背景を短く言う → 議事内容を書く → 決定事項と未決事項を分ける → 期限と担当者を書く
- 提交前自查：是否说清对象、动作、确认路径、下一步。

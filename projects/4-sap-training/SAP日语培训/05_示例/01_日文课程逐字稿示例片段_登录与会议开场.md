# 日文课程逐字稿示例片段：SAP 登录与会议开场

> 这个示例不是完整一课，只演示“课堂逐字稿”应该写到什么颗粒度。

---

## 课堂片段：SAP GUI 登录说明

【时间】20:00-35:00

【讲师中文】
大家注意，今天我们不是只背「login = ログインする」。真正的项目现场里，顾问要能一步一步教用户进入系统。日本用户听你说明时，最需要的是清楚、礼貌、顺序明确。

我们先看一句可以直接用的话：

【讲师日语】
これから SAP GUI のログイン手順をご説明します。

【中文解释】
接下来我说明 SAP GUI 的登录步骤。

【学生跟读】
これから SAP GUI のログイン手順をご説明します。

【讲师中文】
这里的「手順」就是步骤。不要说「方法」也可以，但项目现场说「手順」更像操作说明。

【板书】
- 手順：步骤
- 起動する：启动
- 入力する：输入
- コマンドフィールド：command field
- T コード：T-code

【讲师日语】
まず SAP GUI を起動してください。
次に、クライアント、ユーザー ID、パスワードを入力してください。
ログイン後、コマンドフィールドに T コードを入力します。

【中文解释】
请先启动 SAP GUI。然后输入 client、user ID 和 password。登录后，在 command field 里输入 T-code。

【学生练习】
请大家把 T-code 替换成 FB50、ME23N、SPRO。

【学生想定回答】
コマンドフィールドに FB50 を入力してください。
コマンドフィールドに ME23N を入力してください。
コマンドフィールドに SPRO を入力してください。

【讲师纠错】
刚才有同学说「T コードを入れてください」。这个能懂，但是给客户做培训时，用「入力してください」更正式、更清楚。

## 课堂片段：会议开场

【时间】00:00-05:00

【讲师中文】
在日本项目里，线上会议一开始通常要确认声音和画面。不要直接进入主题，先确认大家是否能听到、能看到资料。

【讲师日语】
皆さん、おはようございます。
本日はご参加いただき、ありがとうございます。
私の声は聞こえていますでしょうか。
画面は共有されていますでしょうか。

【中文解释】
大家早上好。感谢大家参加今天的会议。能听到我的声音吗？能看到共享画面吗？

【学生练习】
请大家两人一组，一个做顾问，一个做用户。用户说听不清，顾问要礼貌处理。

【示例对话】

顾问：私の声は聞こえていますでしょうか。
用户：少し聞こえにくいです。
顾问：失礼いたしました。少しマイクを調整します。今はいかがでしょうか。
用户：はい、聞こえています。
顾问：ありがとうございます。それでは、本日のアジェンダに入ります。

【讲师纠错】
注意「聞こえにくい」是“听起来有点困难”，比直接说「聞こえない」更柔和。顾问处理时不要说「じゃあもう一回聞いてください」，要说「マイクを調整します」。

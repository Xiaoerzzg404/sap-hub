# SAP 日语课程设计风格手册

## 1. 课程不是翻译课

不要做：

```text
Could you walk me through the current process?
= 現在のプロセスを歩いて説明してくれますか。
```

要做：

```text
現行業務の流れをご説明いただけますでしょうか。
```

原因：

- 日语项目现场不会直译 walk me through。
- 需要使用自然的需求访谈表达。

---

## 2. 课程是顾问动作训练

每一课都要让学生完成一个真实顾问动作：

| 动作 | 示例 |
|---|---|
| 说明 | SAP GUI のログイン手順をご説明します。 |
| 确认 | 認識が合っているか確認させてください。 |
| 追问 | 現在の課題をもう少し具体的に教えていただけますか。 |
| 推进 | 次回までにこちらで整理して共有いたします。 |
| 汇报 | 原因を確認したうえで、対応方針をご連絡いたします。 |
| 收束 | 本日のアクションアイテムを確認します。 |

---

## 3. 语言层级

### 对客户 / 用户

使用自然丁寧語：

```text
確認させてください。
ご説明いただけますでしょうか。
共有いたします。
```

### 对内部顾问

可以简洁一些：

```text
この件、MM 側で確認してもらえますか。
影響範囲を確認して、今日中に共有します。
```

### 对 PM / Leader

强调结论、风险、下一步：

```text
現時点では原因を調査中です。
影響範囲は購買発注登録と請求書照合に限定される見込みです。
本日中に暫定対応案を共有いたします。
```

---

## 4. 日语表达原则

### 自然

不要中式日语：

```text
あなたの要求はスコープの外です。
```

改成：

```text
こちらのご要望は、現時点では今回のスコープ外となる可能性があります。
```

### 清楚

避免过度委婉导致听不懂：

```text
恐れ入りますが、もし差し支えなければ、可能な範囲で・・・
```

改成：

```text
確認のため、エラーメッセージのスクリーンショットを送っていただけますでしょうか。
```

### 可推进

每段沟通都要有下一步：

```text
こちらで影響範囲を確認し、次回の定例会でご報告いたします。
```

---

## 5. SAP 术语处理原则

### 日本项目常保留英文 / 片假名

| 英文 | 日语项目常用表达 |
|---|---|
| SAP GUI | SAP GUI |
| T-code | T コード |
| configuration | 設定 / コンフィグ |
| customizing | カスタマイズ |
| go-live | 本番稼働 / Go-live |
| hypercare | 稼働後サポート / ハイパーケア |
| UAT | ユーザー受入テスト / UAT |

### 不要过度翻译 SAP 原词

例如：

- SAP GUI 不要翻成 “SAP 图形用户界面”。
- T-code 不要翻成 “事务代码” 后完全不保留 T-code。
- SPRO、FB50、ME23N、SU01、PFCG 等 T-code 必须保留。

---

## 6. 每课都要有最终输出

每一课必须设计一个“学生最后能说出来”的输出。

示例：

| 主题 | 最终输出 |
|---|---|
| SAP 登录 | 用日语教用户登录 SAP |
| 会议开场 | 主持 5 分钟会议开场 |
| 需求访谈 | 询问 AS-IS 并复述理解 |
| P2P | 90 秒说明采购到付款流程 |
| 三点照合 | 回答三点照合是哪三点 |
| 权限问题 | 请求截图并说明下一步 |
| 上线准备 | 说明 cutover 和 hypercare |

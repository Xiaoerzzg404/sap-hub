# 课堂训练方法库

## 1. Shadowing

用途：让学生先获得语音和句型熟悉度。

流程：

1. 讲师读。
2. 学生跟读。
3. 分块跟读。
4. 遮住中文再读。
5. 放入场景。

示例：

```text
認識が合っているか確認させてください。
```

---

## 2. Substitution Drill

用途：让学生从一个句子扩展到多个 SAP 场景。

示例：

基础句：

```text
コマンドフィールドに T コードを入力してください。
```

替换：

```text
コマンドフィールドに FB50 を入力してください。
コマンドフィールドに ME23N を入力してください。
コマンドフィールドに SPRO を入力してください。
```

---

## 3. 30 秒 Micro Training

用途：训练顾问短说明能力。

结构：

```text
目的 → 步骤 / 流程 → 确认下一步
```

示例任务：

```text
请用 30 秒日语说明 SAP GUI 登录流程。
```

---

## 4. Role Play

用途：模拟真实项目互动。

角色建议：

- SAP 顾问
- 业务用户
- Key user
- PM
- Basis 顾问
- ABAP 开发
- FI/MM/SD 跨模块顾问

---

## 5. Error Correction Drill

用途：训练学生把中式日语改成项目日语。

示例：

错误：

```text
要求はスコープ外です。
```

改写：

```text
こちらのご要望は、現時点では今回のスコープ外となる可能性があります。
```

---

## 6. Consultant Storytelling

用途：训练面试和项目经验说明。

结构：

```text
项目背景 → 我的角色 → 负责范围 → 遇到的问题 → 采取的行动 → 结果
```

日语模板：

```text
私は FI 領域のコンサルタントとして、要件定義、設定、テスト、ユーザーサポートを担当しました。
特に MM との連携部分では、入庫、請求書照合、会計伝票の自動生成に関する課題対応を経験しました。
```

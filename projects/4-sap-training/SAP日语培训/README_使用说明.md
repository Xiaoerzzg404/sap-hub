# SAP 日语培训 Codex 指导包｜使用说明

本文件包用于指导 Codex 将已经整理好的 **24 次 SAP 英文培训课逐字稿 + 总结稿**，逐课改造成 **SAP 日语培训课程**。

> 核心思想：不要把英文课逐字翻译成日语，而是把原课中的 SAP 顾问场景、业务动作、课堂互动、学生练习和可交付输出，迁移成适合中国 SAP 顾问进入日本项目的实战日语训练。

---

## 一、你应该怎么使用这个文件包

建议按以下顺序使用：

1. 先读 `00_总览/00_项目目标与处理原则.md`
2. 再读 `03_风格手册/01_SAP日语课程设计风格手册.md`
3. 把 `01_提示词/01_Codex系统总提示词.md` 作为 Codex 的长期角色提示词
4. 每处理一课，把该课的：
   - 逐字稿 markdown
   - 总结稿 / 时间线培训教程 markdown
   连同 `01_提示词/02_单课课程设计提示词.md` 和 `01_提示词/03_单课日文课程逐字稿提示词.md` 一起交给 Codex
5. 如果要一次性批量处理 24 次课，使用 `06_快速复制版/Codex一次性总提示词_24课完整生产.txt`

---

## 二、每次课必须生成什么

每一课建议至少生成两个主文件：

```text
lesson_XX_SAP日语培训课程设计稿.md
lesson_XX_SAP日语课堂逐字稿.md
```

可选增强文件：

```text
lesson_XX_学生讲义.md
lesson_XX_术语表.md
lesson_XX_作业与评分表.md
lesson_XX_待复核清单.md
```

---

## 三、最重要的新增要求：每课都要生成“新版本日语课程逐字稿”

这里的“逐字稿”不是原视频 ASR 的逐字翻译，而是：

> 一份讲师可以照着上课的 SAP 日语课课堂脚本。

它应该包括：

- 讲师中文讲解
- 讲师日语示范
- 学生日语练习句
- 学生可能回答
- 讲师纠错话术
- 角色扮演台词
- 板书内容
- 课堂节奏和时间安排
- 课后作业说明

推荐标记：

```text
【时间】00:00-05:00
【讲师中文】今天我们把 SAP 登录这个场景转成日本项目现场表达。
【讲师日语】皆さん、おはようございます。本日は SAP GUI のログイン手順を練習します。
【学生練習】SAP GUI を起動してください。
【想定回答】はい、起動しました。
【讲师纠错】这里不要说「開けてください」，项目现场更自然的是「起動してください」。
```

## 四、建议的整体工作流

```text
输入：
  24 份逐字稿
  24 份总结稿 / 时间线培训教程

Codex 处理：
  1. 逐课读取原课内容
  2. 提取 SAP 场景、术语、课堂互动、学生练习
  3. 转成 SAP 日语课程设计
  4. 生成该课日语课堂逐字稿
  5. 生成术语表、句型库、练习和作业
  6. 标注 ASR 待复核点

输出：
  24 份课程设计稿
  24 份日语课堂逐字稿
  总目录
  总术语表
  总句型库
  待复核总表
```

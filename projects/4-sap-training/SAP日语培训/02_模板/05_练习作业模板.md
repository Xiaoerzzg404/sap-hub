# 练习与作业模板

## 1. Shadowing

### 句子
```text
認識が合っているか確認させてください。
```

### 练习方式
1. 听讲师读 1 遍。
2. 学生跟读 3 遍。
3. 替换关键词。
4. 放入场景中说完整句。

## 2. Substitution Drill

### 基础句
```text
コマンドフィールドに T コードを入力してください。
```

### 替换词
- T コード → FB50
- T コード → ME23N
- T コード → SPRO

### 练习句
```text
コマンドフィールドに FB50 を入力してください。
コマンドフィールドに ME23N を入力してください。
コマンドフィールドに SPRO を入力してください。
```

## 3. 30 秒 Micro Training

### 任务
请用日语向用户说明如何登录 SAP GUI。

### 输出结构
1. 目的
2. 操作步骤
3. 确认用户是否能操作

### 示例答案
```text
これから SAP GUI のログイン手順をご説明します。
まず SAP GUI を起動してください。
次に、クライアント、ユーザー ID、パスワードを入力します。
ログイン後、コマンドフィールドに T コードを入力します。
ここまでご自身で操作できそうでしょうか。
```

## 4. Role Play

### 背景
用户无法登录 SAP，提示账号被锁。

### 角色 A：用户
- 不知道为什么无法登录。
- 可以看到错误消息。
- 不确定要不要截图。

### 角色 B：SAP 顾问
- 礼貌确认问题。
- 请求截图。
- 判断可能是账号锁定或权限问题。
- 告诉用户下一步。

### 必须使用句型
```text
エラーメッセージのスクリーンショットを送っていただけますでしょうか。
ユーザー ID がロックされている可能性があります。
Basis チームに確認いたします。
確認でき次第、ご連絡いたします。
```

## 5. 作业模板

### 词汇作业
整理本课 20 个 SAP 日语术语。

### 句型作业
选择 10 个句型，各造 1 个项目现场句。

### 录音作业
录制 60 秒日语说明：说明本课 SAP 场景。

### 项目化输出作业
写一封日语 follow-up 邮件或会议纪要。
